# 운영 이어받기 체크리스트

> 2026-11-04 기준. 프로젝트(11/11) 이후 회사에서 매일 예측을 계속 돌릴 경우를 위한 안내.
> 지금은 팀 노트북이 매일 계산해 웹에 올린다. 이어받으려면 아래 순서대로 준비한다.
> 운영에는 우리 **저장소 코드**가 필요하다 (이 폴더의 문서만으로는 돌지 않음). 필요하면 팀에 저장소 접근과 데이터 전달을 요청한다.

## 0. 먼저 정할 것
- [ ] **어디서 돌릴지**: Windows PC 또는 서버 한 대. **Windows 권장** (주간 전력수요전망 이미지를 Windows 내장 한국어 OCR로 읽음).
- [ ] **웹을 어떻게 보여 줄지**: ① 사내 공유 폴더에 웹 폴더를 두고 `index.html`을 열기 (서버 불필요) ② 회사 GitHub + Render 같은 정적 호스팅 ③ 사내 웹서버.
- [ ] **누가 매일 확인할지**: 실행 기록 확인 담당 (하루 1분).

## 1. 받을 것 (팀 → 현업)
- [ ] 저장소 코드 (GitHub 접근 권한 또는 압축 파일)
- [ ] `data/` 폴더 (약 3.8GB): 원본 자료, 정제 자료, 학습된 모델 파일. 특히 일주일 미세조정 모델(`data/processed/smp_forecast_app/wz3/ft/ft2025f`, 약 100MB)은 다시 만들려면 1시간 걸림
  - 받지 않고 새로 모을 수도 있다: 03_data.md 순서대로 (과거 수집 몇 시간 + 직접 내려받을 파일)
- [ ] Hugging Face 모델 캐시 (`amazon/chronos-2`, `autogluon/chronos-2-small`): 인터넷이 되는 곳이면 첫 실행 때 자동으로 받는다 (운영 코드는 그 뒤 오프라인 모드로 씀)
- ✗ **인증키는 넘기지 않는다.** 지금 키는 팀원 개인 발급이다 → 2절

## 2. 인증키 직접 발급 (승인까지 하루 이상)
- [ ] 공공데이터포털(data.go.kr) 일반 인증키 → 활용 신청: 계통한계가격 및 수요예측(하루전 발전계획용), 특일 정보, 기상청 중기예보 조회서비스, 오늘전력수급현황조회, 지역별 시간별 태양광 발전량 정보, 제주계통운영정보
- [ ] 기상청 API허브(apihub.kma.go.kr) 인증키 → 단기예보 구역별 육상예보(`fct_afs_dl`)
- [ ] 저장소 맨 위에 `.env` 파일을 만들어 두 줄 저장 (커밋하지 않음)
  ```
  DATA_GO_KR_API_KEY=발급받은 일반 인증키(Decoding)
  KMA_APIHUB_KEY=발급받은 API허브 키
  ```
- EPSIS, 전력거래소 홈페이지, 가스공사 요금표, Open-Meteo는 키가 필요 없다.

## 3. 설치
- [ ] Python 3.12, 패키지: pandas, numpy, scikit-learn, lightgbm, torch, chronos-forecasting, transformers, interpret, openpyxl, requests, python-dotenv, matplotlib
- [ ] 메모리 16GB 이상 권장 (매년 12/31 미세조정이 메모리를 많이 씀), 디스크 여유 10GB
- [ ] Windows 한국어 OCR 언어 기능 (설정 → 언어 → 한국어 → 광학 문자 인식)
- [ ] 실행 파일 경로 고치기: `smp_forecast_app/ops/ops_daily.bat`, `ops_actuals.bat`, `ops_train.bat` 안의 `C:\developer\SMP`(저장소 위치)와 `C:\Python312\python.exe`(파이썬 위치). **이 파일들은 cp949(ANSI)·CRLF로 저장**해야 한다 (UTF-8로 저장하면 한글 주석을 명령으로 잘못 읽음)

## 4. 첫 실행 확인 (예약 전에 손으로)
- [ ] 웹 자동 푸시 없이 시험: `set SMP_NO_PUSH=1` 후 `python -m smp_forecast_app.src.ops daily`
- [ ] `data/processed/smp_forecast_app/ops/run_log.txt`에서 수집 → 일주일 K3 → 한 달 → 급락 → 급등 → 경보 근거 → 제주 → 웹 데이터까지 '완료'가 찍히는지 본다 (처음 약 20분, 이후 매일 약 15분)
- [ ] `smp_forecast_app/web/index.html`을 열어 기준일이 오늘인지 확인
- [ ] 공표값 반영 시험: `python -m smp_forecast_app.src.ops actuals`

## 5. 예약 작업 3개 (작업 스케줄러)
실행 방식은 모두 `wscript.exe //B smp_forecast_app\ops\run_hidden.vbs ops_○○.bat` (창 없이 실행).

| 작업 | 시각 | 하는 일 |
|---|---|---|
| 매일 예측 (`ops_daily.bat`) | 매일 15:30 + 23:30까지 매시 재시도 + 로그온·절전 해제 3분 뒤 | 수집 → 예측(육지·제주) → 웹 데이터. 이미 했으면 바로 끝남. 꺼져 있던 날은 최대 14일 따라잡음 |
| 공표값 반영 (`ops_actuals.bat`) | 매일 21:30, 23:50 | 내일 공표 SMP, 그날만 받을 수 있는 육지 5분 수급 |
| 주간 학습 (`ops_train.bat`) | 매주 일요일 03:00 | 제주 보정 모델 학습 |

- [ ] 세 작업 모두: "예약 시간을 놓치면 가능한 빨리 실행", "작업 실행 위해 절전 모드 해제", "실패 시 15분 간격 3회 재시도"
- [ ] PC 절전은 "안 함" 권장 (절전 중에는 깨어나지 않는 경우가 있었음)
- [ ] GitHub로 웹을 올리지 않으면 bat 파일에 `set SMP_NO_PUSH=1` 한 줄 추가

## 6-1. 일주일 모델 연 1회 미세조정 (매년 12/31)
일주일 예측(K3)의 평일 모델은 Chronos-2 small을 **우리 SMP 자료로 1년에 한 번 다시 학습(미세조정)**한 판을 쓴다. 해마다 가격 수준·모양이 바뀌므로 그해까지의 자료를 반영하기 위해서다 (분기마다 하는 것과 차이가 0.004원뿐이라 연 1회로 정함).

| 항목 | 내용 |
|---|---|
| 언제 | **매년 12월 31일**. 그해 12/31까지 자료로 학습한 판을 기준일 12/31부터 다음 해 12/30까지 쓴다 |
| 자동 실행 | 12/31 15:30 매일 예측이 시작될 때 그해 판이 없으면 **먼저 미세조정을 하고** 예측한다 (별도 예약 불필요). 그날 웹 갱신이 약 1시간 늦어진다 |
| 손으로 미리 하기 | 12/31 오전에 `python -m smp_forecast_app.src.wz3_ops --finetune 2026` (연도 = 그해). 15:30 전에 끝나면 그날 예측이 늦어지지 않는다 |
| 걸리는 시간·자원 | CPU 약 1시간, 메모리를 많이 씀 (16GB 이상 권장). 다른 무거운 작업과 겹치지 않게 |
| 설정 | 학습률 1e-6, 500단계, 배치 32, 과거 2,048시간, 공변량 = 휴무일·요일유형·명절 (바꾸지 않는다) |
| 결과 위치 | `data/processed/smp_forecast_app/wz3/ft/ft{연도}f/` (약 100MB). 지우지 않는다 |
| 확인 | 다음 날 실행 기록에 `[주의] ft{연도}f 판이 없어 … 대신함`이 **없으면** 정상. 있으면 위 '손으로' 명령을 실행 |
| 실패해도 | 직전 해 판으로 계속 예측한다 (멈추지 않음). 정확도만 조금 떨어질 수 있다 |

- 12/31에는 PC를 켜 두고, 그날 예측이 늦게 나와도 정상이다.
- 오차 보정(LightGBM)은 대상 달마다 자동으로 다시 학습되므로 따로 할 일이 없다.

## 7. 문제가 생기면
| 증상 | 확인할 곳·원인 |
|---|---|
| 웹 상단에 "예측이 N일 늦어지고 있습니다" | PC가 꺼져 있었거나 예약 작업이 실패. `run_log.txt` 마지막 줄 |
| 수집 종료코드가 0이 아님 | 인증키 만료·일일 호출 한도(다음 실행에 이어 받음)·사이트 구조 변경 |
| 주간 전력수요전망 값이 빈칸 | OCR이 이미지를 못 읽음 (약 10%). 빈칸으로 예측하므로 멈추지는 않음 |
| 가스요금 수집 오류 | 가스공사 요금표 페이지가 바뀜 → 수집 코드 주소 확인 |
| 12/31 이후 일주일 예측에 `[주의] 판이 없어` | 미세조정이 안 됨 → `python -m smp_forecast_app.src.wz3_ops --finetune 연도` |
