## 어떻게 쓰고 있나
1. **지시 파일이 3층으로 쌓인다.** AI는 대화를 시작할 때 저장소의 `CLAUDE.md`를 자동으로 읽는다.
   - 루트 `CLAUDE.md` — 모든 과제 공통 규칙 (팀 합의, 공정성, 누수 금지). **가장 우선.**
   - 과제 폴더 `CLAUDE.md` — 그 과제의 목표·정의·폴더 구조 (`drop_classifier/`, `smp_forecast_app/`, `surge_classifier/`).
   - 과제 `docs/PLAN.md` — 체크리스트와 **결정 기록**(날짜·결정·근거). 대화가 바뀌어도 왜 그렇게 정했는지 이어진다.
2. **채팅 하나에 역할 하나.** 모델별로 채팅을 나누고(R1 급락, R4 급등 …), 총괄 채팅(R0)이 결과를 받아 웹·운영에 붙인다. 역할마다 고칠 수 있는 파일을 정해 서로 덮어쓰지 않게 했다.
3. **프롬프트는 같은 틀**을 쓴다: 역할 → 먼저 읽을 문서 → 결정된 것(바꾸지 않을 것) → 할 일(단계마다 보고) → 지킬 것 → 첫 단계. 규칙을 프롬프트에 다시 쓰지 않고 "먼저 읽기"로 문서를 가리킨다.
4. **단계마다 멈춘다.** AI가 한 단계를 끝내면 결과 요약과 다음 단계 제안을 보고하고, 사람이 확인한 뒤에 진행한다. 채점 규칙은 채점 전에 먼저 정한다(2026 시험 구간으로 고르지 않기 위해).
