## 추천 순서
1. 01_rules.md를 읽는다.
2. 03_data.md 4절의 인증키를 신청한다 (승인까지 하루 이상 걸릴 수 있음).
3. 04_follow_prompts.md를 1단계부터 차례로 붙여 넣는다. 각 단계 끝의 숫자와 비슷하게 나오면 다음으로 간다.

## 우리가 일한 방식 (참고)
1. **지시 파일을 쌓는다.** AI는 대화를 시작할 때 프로젝트의 `CLAUDE.md`를 자동으로 읽는다. 공통 규칙(가장 우선) → 과제별 목표·정의 → 과제별 결정 기록(날짜·결정·근거) 순으로 두어, 대화가 바뀌어도 왜 그렇게 정했는지 이어지게 했다.
2. **채팅 하나에 역할 하나.** 급락·급등·일주일·한 달·근거 문장을 채팅별로 나누고, 총괄 채팅이 결과를 받아 웹·운영에 붙였다. 역할마다 고칠 수 있는 파일을 정해 서로 덮어쓰지 않게 했다.
3. **프롬프트는 같은 틀**: 역할 → 먼저 읽을 문서 → 결정된 것(바꾸지 않을 것) → 할 일(단계마다 보고) → 지킬 것 → 첫 단계.
4. **단계마다 멈춘다.** AI가 한 단계를 끝내면 결과와 다음 제안을 보고하고, 사람이 확인한 뒤 진행한다. 채점 규칙은 채점 전에 먼저 정한다 (2026 평가 구간으로 고르지 않기 위해).
