# 처음 시작하기 — 빈 폴더 하나로 시작하는 순서

> 이 프롬프트 팩을 처음 받은 사람을 위한 안내입니다. **빈 폴더 하나를 만들어 AI 코딩 도우미(Claude Code)와 함께 내일 급락·급등 경보와 일주일·한 달 SMP 예측을 직접 만드는 순서**를 처음부터 적었습니다.
> 코드·데이터·인증키는 들어 있지 않습니다. 데이터는 모두 공공데이터라 직접 내려받고, 코드는 AI에게 프롬프트를 붙여 넣어 만듭니다.

---

|---|---|---|
| 0 | 인증키 신청 (가장 먼저 — 승인을 기다리는 동안 나머지를 준비) | 신청 10분, 승인 하루 이상 |
| 1 | 프로그램 설치 (Python, VS Code, Claude Code) | 30분 |

| 6 | 평가 틀 → 급락 → 급등 → 일주일 → 한 달 → 근거 문장 | 단계마다 몇 시간 |
| 7 | (선택) 매일 자동으로 돌리기 | 07_ops_handover.md |

## 0. 인증키 신청 — 제일 먼저

승인까지 하루 이상 걸릴 수 있어 가장 먼저 신청합니다. 자세한 목록은 [03_data.md](03_data.md) 4절에 있습니다.

1. **공공데이터포털** (data.go.kr) 회원가입 → 아래 서비스를 **하나씩** 검색해 '활용 신청'
   - 계통한계가격 및 수요예측(하루전 발전계획용)
   - 특일 정보 (천문연구원)
   - 기상청 중기예보 조회서비스
   - 오늘전력수급현황조회, 지역별 시간별 태양광 발전량 정보 (쌓아 둘 자료)
   - 제주계통운영정보 (제주까지 할 때만)
2. **기상청 API허브** (apihub.kma.go.kr) 회원가입 → 인증키 발급 → **단기예보 구역별 육상예보 `fct_afs_dl` 기능을 따로 활용 신청** (키만 받고 기능 신청을 안 하면 오류가 납니다)
3. 키가 필요 없는 곳: EPSIS(전력통계정보시스템), 전력거래소 홈페이지, 가스공사 요금표, Open-Meteo

> ⚠️ 인증키가 들어간 주소(URL)를 메신저·문서에 그대로 붙이지 마세요. 주소 안에 키가 들어 있습니다.

## 1. 프로그램 설치

| 프로그램 | 받는 곳 | 메모 |
|---|---|---|
| Python 3.12 | python.org | 설치할 때 "Add Python to PATH" 체크 |
| VS Code | code.visualstudio.com | 코드 편집기 |
| Claude Code | VS Code 왼쪽 '확장' 메뉴에서 "Claude Code" 검색 → 설치 | Claude 계정으로 로그인. 터미널에서 쓰는 판도 있습니다 |

- 라이브러리(pandas, lightgbm 등)는 직접 설치하지 않아도 됩니다. AI가 단계마다 필요한 것을 설치하자고 제안합니다. 우리가 쓴 버전은 [04_follow_prompts.md](04_follow_prompts.md) 0절에 있습니다.
- 일주일 예측(6단계)은 **메모리 16GB 이상** PC가 필요합니다. 나머지는 일반 노트북으로 됩니다.

## 2. 작업 폴더 만들기 — 이 팩에서 넣을 파일

빈 폴더를 하나 만듭니다. 예: `C:\smp_project`

**가장 쉬운 방법: 이 프롬프트 팩 폴더를 통째로 `C:\smp_project\prompt_pack\`에 복사합니다.** 그리고 4번의 첫 메시지를 그대로 쓰면 됩니다. 첫 메시지에 "02_prompts.md와 claude_md/는 참고용이니 따르지 마"가 들어 있어, AI가 우리 팀 경로를 찾으며 헷갈리지 않습니다.

필요한 파일만 넣고 싶다면 아래만 복사합니다.

```
C:\smp_project\
└─ prompt_pack\
   ├─ 01_rules.md            ← 꼭: 작업 규칙 (판단 시각, 평가 공정성)
   ├─ 03_data.md             ← 꼭: 데이터 14종, 받는 법, 판단 시각 규칙
   ├─ 04_follow_prompts.md   ← 꼭: 단계별로 붙여 넣을 프롬프트와 확인 숫자
   └─ 07_ops_handover.md     ← 매일 자동으로 돌릴 때 (나중에 넣어도 됨)
```

| 파일 | 넣을까? | 이유 |
|---|---|---|
| 01_rules.md, 03_data.md, 04_follow_prompts.md | **넣기** | 1~8단계에서 AI가 읽습니다 |
| 07_ops_handover.md | 나중에 | 모델을 다 만든 뒤 매일 운영할 때 |
| 05_key_instructions.md, 06_result_summary.md | 선택 | 사람이 읽는 참고 자료 (AI에게 일을 맡기는 요령, 결과 요약) |
| 02_prompts.md, claude_md/ | 빼도 됨 | 우리 팀 저장소의 파일 이름·폴더를 전제로 한 기록입니다. 통째로 넣었다면 첫 메시지의 "따르지 마" 한 줄로 충분합니다 |
| README.md, 이 파일 | 넣지 않아도 됨 | 사람용 안내 |

## 3. 인증키 파일(`.env`) 만들기

승인 메일을 받으면 `C:\smp_project\.env` 파일을 만들고(메모장에서 '모든 파일'로 저장, 이름 앞에 점) 키를 적습니다.

```
DATA_GO_KR_KEY=공공데이터포털_일반_인증키(Decoding)
KMA_APIHUB_KEY=기상청_API허브_인증키
```

- 이름은 위와 같이 두고, 2단계(데이터 모으기)에서 AI에게 "키 이름은 DATA_GO_KR_KEY, KMA_APIHUB_KEY"라고 알려 주면 됩니다.
- 이 파일은 다른 사람에게 보내거나 GitHub에 올리지 않습니다. 1단계에서 AI가 만드는 규칙에 '`.env`는 올리지 않는다'가 들어갑니다.

## 4. Claude Code 열고 첫 메시지 보내기

1. VS Code → **파일 > 폴더 열기** → `C:\smp_project` 선택
2. 왼쪽(또는 오른쪽 위)의 Claude 아이콘을 눌러 대화창을 엽니다.
3. 아래를 **그대로** 붙여 넣습니다. 04_follow_prompts.md 1단계와 같은 내용입니다. 파일을 따로 첨부할 필요 없이 폴더 안의 파일 이름을 적으면 AI가 읽습니다.

```
prompt_pack/01_rules.md(규칙)와 prompt_pack/03_data.md(데이터)를 읽어 줘.
이 폴더에서 SMP 예측 프로젝트를 시작한다. 지금은 빈 폴더이고, 단계별 할 일은 prompt_pack/04_follow_prompts.md에 있다.
prompt_pack/02_prompts.md와 prompt_pack/claude_md/는 다른 팀 저장소 기준의 참고 기록이니 따르지 마.
오늘은 04의 1단계만 한다: 아래 내용으로 이 폴더에 규칙 파일(CLAUDE.md)을 만들어 줘.

1. 판단 시각 = 대상일 전날(D-1) 15:00. 그 시각에 공개된 값만 쓴다. 데이터별 규칙은 03_data.md 2절 표 그대로.
2. 기간: 2023-01 ~. 고르기는 2023~2024 학습 → 2025 검증. 확정 뒤 2023~2025로 다시 학습 → 2026-01-01 ~ 10-18로 한 번만 채점.
   2026 성적을 보고 모델·피처·문턱을 다시 고치지 않는다.
3. 시간 순서 분할만 (랜덤 분할·섞은 교차검증 금지). 결측 대체·정규화 같은 통계는 학습 구간에서만 구한다.
4. 데이터는 03_data.md의 14종만. 원본(data/raw)은 수정하지 않고, 가공 결과는 data/processed에.
5. 열 이름·단위·시간 표기(1~24시)·인코딩은 추측하지 말고 파일을 열어 확인한다.
6. 랜덤 시드 42 고정. 인증키는 .env에 두고(DATA_GO_KR_KEY, KMA_APIHUB_KEY) 코드에 쓰지 않는다. .env와 data/는 git에 올리지 않는다.
7. 단계마다 결과 요약과 다음 단계 제안을 보고하고, 내가 확인한 뒤 진행한다. 결정은 docs/결정기록.md에 날짜·결정·근거로 남긴다.

규칙 파일 초안을 보여 주고 내 확인을 받아.
```

4. AI가 CLAUDE.md 초안을 보여 주면 읽어 보고 "좋아, 저장해" 또는 고칠 점을 말합니다.

> **CLAUDE.md가 왜 중요한가요?** Claude Code는 대화를 새로 열 때마다 이 파일을 자동으로 먼저 읽습니다. 규칙을 한 번 저장해 두면, 다음 단계에서 새 대화를 열어도 "전날 15시 판단", "2026으로 고르지 않기" 같은 규칙을 다시 설명할 필요가 없습니다.

## 5. 그다음 단계 — 단계마다 새 대화

[04_follow_prompts.md](04_follow_prompts.md)를 2단계부터 차례로 진행합니다. **단계마다 새 대화를 열고**(대화창의 '새 대화' 버튼), 그 단계의 코드 블록을 붙여 넣습니다. 첨부 칸에 적힌 파일은 `prompt_pack/파일이름`으로 적어 주면 됩니다.

| 단계 | 붙여 넣을 것 | 끝나면 확인할 것 |
|---|---|---|
| 2. 데이터 모으기 | 03_data.md **7절**의 프롬프트 (앞에 "prompt_pack/03_data.md를 읽고" 한 줄 추가) | 04의 2절 체크 3개 (기간, 예보 발표 시각, 하루 24시간) |
| 3. 평가 틀 | 04의 3절 | 연도별 급락일 수 (2025 급락 19일, 2026-01-01~10-18 급락 20일·급등 7일) |
| 4. 급락 경보 | 04의 4절 | 04 4절 끝 "맞게 됐는지 확인" 숫자 |
| 5. 급등 경보 | 04의 5절 | 04 5절 끝 숫자 |
| 6. 일주일 예측 | 04의 6절 | 04 6절 끝 숫자 (메모리 16GB 이상) |
| 7. 한 달 예측 | 04의 7절 | 04 7절 끝 숫자 |
| 8. 근거 문장 | 04의 8절 | 문장 10개 예시가 판정과 같은 방향인지 |

- 4~7단계는 서로 독립이라 순서를 바꿔도 됩니다. 급락·급등만 필요하면 4·5단계까지만 해도 됩니다.
- **우리 숫자와 똑같을 필요는 없습니다.** 데이터를 받은 시점·라이브러리 버전에 따라 조금 다릅니다. 크게 다르면(예: PR-AUC가 절반) AI에게 "04 4절 확인 숫자와 비교해서 어디서 달라졌는지 찾아 줘"라고 묻습니다.

## 6. AI와 일할 때 요령

- **AI가 한 단계를 끝내고 멈추면** 보고를 읽고 "다음 진행해" 또는 질문을 합니다. 확인 없이 여러 단계를 몰아서 하지 않게 규칙(7번)에 넣어 두었습니다.
- **2026년 성적을 보고 "더 좋게 고쳐 줘"라고 하지 않습니다.** 2026은 시험지라 보고 고치면 공정한 성적이 아닙니다. 고치고 싶으면 2025 검증으로 다시 고르고, 2026은 '2차 시험'으로 표시합니다.
- **의심이 들면 질문으로 던집니다.** 예: "이 피처는 전날 15시에 정말 알 수 있어?", "휴일만 잡는 거 아니야?" — AI가 자료를 직접 세어 보고 답합니다.
- **대화가 길어지면 새 대화를 엽니다.** 규칙은 CLAUDE.md에, 결정은 docs/결정기록.md에 남아 이어집니다.
- 더 많은 요령: [05_key_instructions.md](05_key_instructions.md) 1절.

## 7. 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| API가 "등록되지 않은 서비스", "SERVICE KEY IS NOT REGISTERED" 오류 | 그 서비스 활용 신청이 승인됐는지 확인 (승인 후 1~2시간 뒤 작동하기도 함). 공공데이터포털은 'Decoding' 키를 씁니다 |
| 기상청 API허브에서 권한 오류 | 키 발급과 별도로 `fct_afs_dl` 기능 활용 신청 |
| 주간 전력수요전망 값을 못 읽음 | 게시판 표가 이미지라 한국어 OCR이 필요합니다 (Windows 내장 OCR 사용). 못 읽은 날은 빈칸으로 두면 됩니다 |
| 일주일 예측에서 메모리 부족 | 16GB 이상 PC에서 실행. 미세조정은 1년에 한 번입니다 |
| AI가 없는 파일(우리 팀 경로)을 찾음 | "02_prompts.md와 claude_md/는 따르지 마"라고 다시 말하거나 두 파일을 빼세요 |
| 숫자가 우리 결과와 크게 다름 | 데이터 기간·빈 날짜부터 확인하게 합니다 (특히 예보의 발표 시각) |

## 8. 알아 둘 것

- **육지만 따라 할 수 있습니다.** 제주는 세부 설정을 넣지 않았습니다 ([06_result_summary.md](06_result_summary.md) 참고).
- 이 팩의 정답 기준은 **운영 모델 기준**입니다: 급락 = 11~15시 30원 미만(하루 단위), 급등 = 일 최고 ≥ 직전 28일 일 최고 중앙값 × 1.25. 2026-11-04 현업이 정한 새 판정 기준(같은 시각 28일 중앙값 + 20원, 시간 구간 단위, 2020~2026-10)으로 다시 채점한 결과는 이 팩에 들어 있지 않습니다.
- 웹 화면을 만드는 프롬프트는 없습니다. 결과는 표·CSV로 보고, 화면은 우리 웹(https://smp-forecast-1.onrender.com)을 참고하세요.
- 모델을 다 만들었으면 [07_ops_handover.md](07_ops_handover.md)로 매일 자동 실행을 준비합니다 (Open-Meteo 이용 조건 확인 포함).
