# 과제2: SMP 예측 범위(상·하한) 웹앱

> 공통 규칙은 루트 [CLAUDE.md](../CLAUDE.md)를 따른다. 매 세션 이 파일과 [docs/PLAN.md](docs/PLAN.md)를 읽고 진행 단계를 확인한 뒤 작업한다.

## 1. 과제 맥락 (read/ 문서 요약)

- **부족한 점**: 운영 프로그램은 「내일 13시 95원」처럼 숫자 하나만 제시. 시험 삼아 만든 80% 범위는 실제 포함률 52% (원을 너무 작게 그림).
- **할 일** (협의자료 v1.4, 과제2 Q&A): ① 과거 오차(실제 − 예측)를 시간대·요일별로 정리 → ② 오차 하위 10%·상위 10%를 예측값에 더해 상·하한 → ③ 여력 시 LightGBM 분위수 회귀와 비교
- **발표 결과물**: 시간별 예측 상·하한 산출 코드 + 예측 범위 그래프 → **웹앱으로 구현** (교과목 교수 요구)
- **기본 원칙**: 예측값 유지 + 범위 추가 (학생질의 Q2-1). 모델을 바꾸면 점예측 MAE가 나빠지지 않음을 함께 제시.

### 성공 기준 (공식: 전체 시간대 기준)
| 조건 | 내용 |
|---|---|
| 포함률 | 80% 범위 안에 실제 SMP가 든 비율 **75~85%** |
| 폭 | 범위 평균 폭(원) 반드시 병기 — 같은 포함률이면 좁은 쪽이 우수 |
| 평가 기간 | 2025년까지 자료로 범위를 만들고 **2026-01-01 이후로 한 번 채점** |
| 이탈 균형 | 하한 아래·상한 위 이탈이 각각 약 10% |
| 보조 지표 | 휴일 한낮(11~15시)·급락 시간(30원 미만) 포함률 — 목표치 없음 |

## 2. 판단 시각과 예측값 출처

- 공통 판단 시각 **D-1 15:00** (운영 주간 예측과 같음). D일 하루전 수요예측·SMP는 쓰지 않는다.
- 범위를 붙일 예측값은 두 갈래로 다룬다.
  - **A. 담당자 시간별 모델** (`data/smp_edu_data/`, 읽기 전용): OOF 2023-02~2025-12, 2026 홀드아웃. D일 수요예측을 쓰는 23:30 산출 기준이므로 "현업 예측값 유지 + 범위" 검증용. 15시 판단 기준이 아님을 표기.
  - **B. 자체 D+1 모델 (15시 판단)**: 판단 시각에 알 수 있는 값만 사용. 웹앱 주화면용.
- 담당자 운영 기록(시간별 7/30~, 주간 D+1 8/12~)은 2026 구간이므로 **참고 채점만** 한다 (튜닝 금지).

## 3. 평가 공정성
- 방법·파라미터 선택: 2024년까지로 만든 범위를 2025년에 채점해서만 고른다.
- 최종: 2025년까지 자료로 만든 범위를 2026-01-01 ~ 최신일에 한 번 채점.
- 선택 규칙은 2026 채점 전에 코드에 고정한다.

## 4. 폴더
```
smp_forecast_app/
├─ CLAUDE.md, docs/       PLAN.md, NEEDS.md(추가 필요 자료), 결과 정리
├─ src/                   범위 산출·평가·웹 데이터 내보내기 (Python)
├─ outputs/tables|figures 검증표·그래프
├─ web_src/               웹앱 소스: React + TypeScript + Vite + Tailwind + ECharts + react-day-picker
└─ web/                   빌드 결과 index.html 한 파일 + data/forecast_data.js — 서버 없이 파일로 열림
```
- 웹은 육지·제주를 왼쪽 메뉴에서 전환 (육지·공통 = `web/data/forecast_data.js`, 제주 = `web/data/forecast_data_jeju.js`를 제주 선택 때 읽음. 주소 `index.html?region=제주`로 바로 열 수 있음). 제주 모델·결과는 [docs/JEJU.md](docs/JEJU.md).
- 웹 수정: `cd smp_forecast_app/web_src` → `npm install`(처음 한 번) → `npm run build` (→ `web/index.html`). 개발 미리보기 `npm run dev`.
- 데이터만 바뀌면 빌드 불필요: `python -m smp_forecast_app.src.export_web`이 `web/data/forecast_data.js`만 다시 씀 (운영이 매일 자동).
- 과제2 전용 정제 데이터는 `../data/processed/smp_forecast_app/`에 저장.
- 실행: 루트에서 `python -m smp_forecast_app.src.<모듈>`.
