# 과제2 1차 결과 — 시간별 예측 80% 범위 (2026-10-20)

> 공정성: 방법·파라미터는 **2025년 성적만으로** 고르고(선택 규칙: 2025 포함률 75~85% 중 구간점수 최소), **2026-01-01 이후는 한 번만 채점**했다.
> 구간점수(Winkler) = 범위 폭 + 이탈 벌점(벗어난 거리 × 10). 낮을수록 좋음 — 포함률과 폭을 함께 본다.

## 2. 자체 모델 (B, 전날 15시 판단)
- 피처: 달력·휴일, 전날까지의 SMP, 전날까지의 하루전 수요예측, EPSIS 연료비단가(M+2), 태양광 설비(M+2), 주간 전력수요전망(등록 다음 날부터), D-1 11시 발표 육상예보, Open-Meteo D-2 실행 일사·운량. **D일 수요예측은 미사용.**

## 3. 담당자 모델 (A, 예측값 유지 + 범위)
- 예측값은 그대로 두고 범위만 붙임 (학생질의 Q2-1 기본 방침).
- 운영 공표 기록(2026-07-30 ~ 10-02, 1,200시간)에 같은 방법 적용 시 포함률 72.7% — 8~9월 가격 수준 급변(9월 SMP −20%)으로 오차가 커진 구간. 50일 표본이라 ±7%p 흔들림 범위 (`A3_operational_ref.csv`).
- 주의: 담당자 OOF(2023-02~2025-12)는 연속 5구간 교차검증이라 순수 시간 순서가 아닐 수 있음 → A의 2025 선택 성적은 약간 낙관적일 수 있다.

## 3-2. 주간(D+1~D+6) 범위 — 자체 모델 확장
- 현업 실무 주화면은 주간 전망(학생질의 Q4-5) → 기준일 I의 15시에 D = I+H (H=1~6) 예측.
- 점예측 구성은 H=1에서 고른 것을 그대로(지평별 추가 선택 없음). 재학습·범위 오차 이력은 판단일(D-H)까지 자료만.
- 날씨: H=1 단기 육상예보(D-1 11시)+Open-Meteo, H=2~3 기준일 11시 단기 육상예보, H=4~6 기준일 06시 중기예보.
- 범위 방법은 지평마다 2025 성적으로 선택 → 2026 한 번 채점 (`W2_test2026.csv`, 그림 `05_horizon.png`).

# 2차 작업 (2026-10-20 저녁) — 모델 다양화·급락 결합·한 달 전망·웹 개편

> 최신 공표 SMP 수집(10/21분까지, `common.collect.smp_forecast --recent`), 실적 = 엑셀 확정값 + 이후 API 공표값(`load_smp_actual`).
> 1차에서 2026을 이미 채점한 항목을 다시 고른 결과는 **2차 시험**으로 표기. 선택은 여전히 2025 성적만 사용.

## 7. 내일(시간별 D+1) 2차 — `model_v2.py`, `V*` 표
| 후보 (2025 선택 구간) | 전체 MAE | 급락 시간 MAE |
|---|---|---|
| LightGBM (1차) | 8.88 | 80.6 |
| CatBoost | 8.97 | 85.8 |
| **앙상블(LightGBM+CatBoost)** | **8.81** | 83.2 |
| 앙상블 + 급락 결합 w=0.25 (선택) | 8.80 | 80.3 |
| 앙상블 + 급락 결합 w=1.0 | 8.91 | 71.5 |
- 급락 결합(예측값): 과제1 경보일 한낮 예측을 과제1 예상 한낮최저 쪽으로 당김. 비율을 키우면 급락 시간 오차는 줄지만 전체 오차가 커짐 → 규칙(전체 MAE 비악화)상 0.25.
- 급락 결합(범위 하한 내리기): 급락 시간 포함률 0% → 15%, 그러나 구간점수가 미세하게 나빠져 탈락.
- **2차 시험 2026**: 포함률 81.2%, 폭 28.6원, MAE 8.97원(rMAE 0.828) — 1차(8.98원)와 사실상 같음. 결합 전 앙상블은 8.92원으로 결합이 2026에선 약간 손해.
- 결론: 공개 자료로는 급락을 수치 예측에 녹이는 효과가 작다 → **급락은 배지(투트랙)**로 보여 주는 현업 권장안 유지.

## 8. 한 달 전망 (7~34일 뒤, 일별) — `features_daily.py`, `model_monthly.py`(1차), `model_monthly_v2.py`(2차)
- 목표 4종: 일평균, 한낮(11~15시) 평균, 저녁(18~22시) 평균, 한낮 최저. 기준일 15시 판단, 매월 1일 재학습.
- **1차**: LightGBM(원값/비율)·CatBoost·Ridge·앙상블 모두 2025에서 **단순 기준(최근 같은 유형일 4일 평균)을 못 이김**(일평균 9.15 vs 최고 모델 9.73). 2026 일평균 포함률 69.1% 미달.
- **2차**: 단순 기준을 출발점으로, 모델은 "기준 대비 비율"만 학습해 일부 섞음. 2025 최우수 = 기준 + 0.25×(모델 보정) (일평균 8.97, 저녁은 0.5).
- **2차 시험 2026**: 일평균 MAE 11.39원(기준 11.83 대비 3.7% 개선), 포함률 **67.8% — 미달**. 상한 위 이탈 23.6% (2026 7~8월 가격 급등·9월 급락 등 수준 급변이 2025보다 훨씬 큼). 주차별 72.5% → 62.6%로 멀수록 나빠짐.
- 주별 값: 일별 예측의 주 평균 MAE 7.63 vs 주별 전용 모델 9.49 (2025) → **일별 모델의 주 평균 채택** (2026: 10.37 vs 11.19).
- 한 달 앞 급락 감지(한낮최저 < 30원): 1~2주 뒤 ROC 0.76~0.87, 3~4주 뒤 0.68~0.84. 헛경보가 많아 단독 경보로는 부족, 달력(휴무일) 규칙보다 헛경보는 적은 편.
- 웹에서는 **"참고 전망"** 경고와 함께 표시. 개선은 연료비 전망·수급 국면(LNG/석탄 가격결정) 정보가 필요해 보임 — 2026 결과를 보며 더 고치면 반복 튜닝이므로 멈춤.
