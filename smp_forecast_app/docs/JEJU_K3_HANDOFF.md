# 제주 → 총괄 전달 (2026-11-03, R2)

> 육지 일주일 K3·한 달 최종(R6)에 맞춰 제주 일주일·급락·한 달을 다시 고르고 2026을 한 번 채점했다. 근거·표 전체는 [JEJU.md](JEJU.md) 11절.
> R2는 운영·웹 파일(`ops.py`, `export_web.py`, `team_scorecard.py`, `web_src/`, `web/`, `ops/` 기록)을 고치지 않았다. 아래 연결은 총괄 몫이다.
> 운영 함수는 **인자로만** 추가했다 (기본값 = 지금 동작). 총괄이 인자를 바꾸기 전까지 운영은 그대로다. 커밋 `7475bfd`.

## 1. 바뀌는 것 한눈에

| 예측 | 지금 운영 | 새로 켤 것 |
|---|---|---|
| 일주일 | 이전 육지 모델(hourly_log) + 0.25 × 제주 보정 | **육지 K3 + 0.25 × 제주 보정(시간별 제주 피처)**, 범위 A1 90일 |
| 급락 | S4 KNN, 휴일·주말 문턱, 이전 육지 입력 | **S5 KNN(피처 63개), 전체 날 문턱, 육지 입력 K3** |
| 한 달 | 육지 v2 그대로 (7~34일 뒤, 4지표) | **육지 한 달 최종(R6) 그대로 + 제주 범위** (월말 → 다음 달 일평균) |
| 급등 | 없음 | **없음 (제외, 이유는 5절)** |

→ 세 개를 켜면 **이전 육지 일주일 모델(`ops.weekly` → `hourly_log.csv`)을 제주 때문에 돌릴 필요가 없다.**

## 2. 운영 함수 (15:30 호출 순서)

```python
from smp_forecast_app.src import jz_ops
# 1) 육지 ops.weekly_k3 (지금처럼) — k3_parts.csv.gz에 그 기준일 행이 있어야 함
w = jz_ops.weekly(bases, land="k3")          # [base_date, H, date, hour, y, pred, lo, hi, offday], 기록 jeju/ops/jwz7_log.csv
d = jz_ops.drops(bases, version="all")       # [base_date, date, grade, pred_min, prob] (지금 drops와 같은 열)
#   ROLES 4.1 열이 필요하면 jz_ops.predict(bases, version="all") → [base_date, date, grade, prob, score]
# 월말: R6 육지 한 달 운영 결과 [base_date, date, pred] →
m = jz_ops.monthly_final(land_month)         # [base_date, H, date, pred, lo, hi]
```

| 함수 | 소요 시간 | 자동 학습 | 주의 |
|---|---|---|---|
| `weekly(bases, land="k3")` | 기준일 2개 약 110초 (피처 표 만들기가 대부분) | 대상 달마다 잔차 모델 `jeju/models/jz4_resid_YYYY-MM.pkl` (그달 첫 실행 +17초) | 육지 `weekly_k3` 다음. 기준일 K3 행이 없으면 그 지평을 건너뛰고 로그 출력 |
| `drops(bases, version="all")` | 기준일 2개 약 24초 | 학습 자료 `jeju/models/jz_drop_all.pkl` (없으면 자동, 고정) | 육지 `weekly_k3` 다음 (K3 H=1 한낮 최저를 씀). 5분 실적은 지금처럼 예측 전에 수집 |
| `monthly_final(land)` | 1초 미만 | 없음 | R6 육지 한 달 함수가 저장소에 들어온 뒤 연결. 범위 분위수는 `JMZ3_choice.json` (해마다 1월 갱신 권장) |

- 일요일 `jz_ops.train()`은 그대로 둬도 된다 (새 경로는 위 자동 학습을 씀).
- 시험 확인 (`SMP_NO_PUSH=1`, 기준일 2026-10-15·16): 급락은 백테스트와 등급·확률·점수가 완전히 같았다. 일주일은 점예측 차이가 평균 0.15원이다 (피처 표를 새로 계산한 차이). 한 달은 0.01원 이내다.

## 3. 웹·팀 비교표 원본 파일

| 예측 | 백테스트 (2025-01-01 ~) | 형식 |
|---|---|---|
| 일주일 | `data/processed/smp_forecast_app/jeju/JWZ7_predictions_hourly.csv` + 운영 `jeju/ops/jwz7_log.csv` | ROLES 4.2 (`base_date, H, date, hour, y, pred, lo, hi, offday, stage`) |
| 급락 | `drop_classifier/outputs/tables/drop_제주_15h.csv` | ROLES 4.1, **label은 모든 날 채움** |
| 한 달 | `data/processed/smp_forecast_app/jeju/JMZ3_predictions_daily.csv` | `base_date, H, date, y, pred, lo, hi` (월말 판단만, 일평균 1지표) |

- 웹이 지금 읽는 `jeju/drop_badge_제주.csv`는 **그대로 두었다**. 바꿀 때 `drop_제주_15h.csv`를 읽으면 된다. 등급은 `없음/주의/경보`다.
- 일주일 범위는 하한을 0원에서 자르지 않는다 (제주는 음수 가격이 있음). 휴일·주말 한낮 하한 보정(`range_adjust`)은 붙이지 않는다 (보정 없이 골랐음).
- 한 달은 4지표(한낮·저녁·한낮 최저)가 없고 **일평균 하나**다. 육지 R6와 같다.
- 이전 결과는 `drop_*_제주*_v1_offday.*`로 보관했다.

## 4. 성적 요약 3줄 (2026-01-01 ~ 10-18, 한 번 채점)

1. **일주일**: MAE 11.16원 (지금 11.18, K3 그대로 11.26). 제주가 육지보다 비싼 시간은 10.82원 (지금 11.06), 포함률 78.6% (지금 77.4%).
2. **급락** (전체 날 291일, 급락 53일): 주의 이상 45 적중·8 놓침·42 헛경보 (재현율 85%, 정밀도 52%). 지금은 43·10·48. Brier 0.106 (지금 0.126).
3. **한 달**: MAE 10.72원, 포함률 78.6%. 지금 모델과 같은 230일로 비교하면 11.47원 vs 14.66원, 포함률 77% vs 54%.

## 5. 제주 급등 — 제외 (사용자 결정 2026-11-03)

- 모델(육지 v3 구성을 제주로 학습)을 만들어 확인했지만, 2025·2026 PR-AUC가 0.03~0.04로 무작위 수준이었다 (2026: 급등 6일 중 1일 적중·헛경보 61).
- 이유:
  - 2024 하반기부터 제주 가격이 육지와 같은 시간이 92%라, 제주 급등이 연 6~7회로 줄었다.
  - 남은 급등의 절반 이상은 제주에서만 한두 시간 튄 단발성이라 전날 정보에 신호가 없다.
  - 나머지는 육지와 같이 오는 날이라 육지 급등 경보가 다룬다.
- **웹 문구 (제주 급등 자리)**: "제주 급등 경보는 제공하지 않습니다. 2025년 이후 제주 급등은 연 6~7회뿐이고 대부분 당일 사정에 따른 단발성이라 전날 정보로 미리 알 수 없었습니다. 육지와 함께 오르는 날은 육지 급등 경보를 참고하세요."

## 6. 발표 때 지킬 표현
