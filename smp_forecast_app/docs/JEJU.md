## 0. 한눈에 보기

### 상태
- **세 예측 모두 모델 확정 + 2026 한 번 채점 완료 (2026-10-25).** 이후 2026 성적으로 모델·피처·문턱을 바꾸면 공정성 규칙 위반이다.
- 남은 일은 운영·웹 연결(과제2 채팅 몫)과 발표 정리뿐이다 (9절).
- **2026-11-03 육지 K3·한 달 최종에 맞춘 재선택 (11절, 이 절이 최우선)**: 일주일 = K3 + 0.25 × 제주 보정(시간별 제주 피처), 급락 = S5 KNN·전체 날 문턱·육지 입력 K3, 한 달 = 육지 한 달 최종 그대로 + 제주 범위, 급등 = 배포하지 않음. 운영 함수는 인자로만 켬(기본 = 지금 동작).
- **2026-10-28 팀 규칙 재선택·2차 (10절) — 사용자 결정으로 운영 반영**: 급락 1차 = 팀 규칙 새 모델(S4 KNN, 2023~2025 학습), 일주일 1차 = 그대로, 일주일 2차(21시) = 육지 2차 + 0.25 × 제주 보정, 한 달 = 육지 한 달 v2 기준. 이전 결과는 `*_v1` 파일. **0절 아래 표·1절 파일 지도는 2026-10-25 기준(v1)이므로 10절이 우선.**

### 최종 모델과 2026 시험 성적 (2026-01-01 ~ 10-23)

| 예측 | 최종 모델 | 2026 성적 | 2025 하반기 (선택 시) | 판단 |
|---|---|---|---|---|
| **일주일** (D+1~7, 시간별) + 80% 범위 | 육지 일주일 최종 예측 + 0.25 × 제주 잔차 보정(LightGBM L1) | MAE **11.08원** · rMAE **0.793** · 포함률 **77.5%** · 평균 폭 34.5원 | 9.68원 · 0.794 · 75.9% · 29.0원 | 성공 기준(포함률 75~85%) 충족, 기준 대비 비율 2025와 같음 |
| **다음 날 급락** (내일 11~15시 최저 < 30원) | 피처 S5 + KNN 분류(이웃 25, 거리 가중) | 54일 중 주의 이상 **39 적중** · 15 놓침 · 헛경보 35 (재현율 72%), 강한 경보 34 적중 · 헛경보 23 (정밀도 60%), ROC-AUC 0.879 | 2025 급락 90% 포착 · 헛경보 72 | 목표 재현율 90% 미달. 1차 후보(S4 RF)가 2026엔 더 좋았음 → 참고 수준으로 설명 |
| **한 달** (7~34일 뒤, 일별) | 육지 한 달 최종 예측 + 최근 제주−육지 차이 (지표별) | rMAE 일평균 0.989 · 한낮 0.949 · 저녁 **1.183** · 한낮 최저 0.877 | 0.966 · 0.980 · 0.908 · 0.966 | 참고 전망 (저녁은 기준보다 나쁨) |

- rMAE = 모델 MAE ÷ 단순 기준 MAE (1보다 작으면 기준보다 나음). 기준: 일주일 = 지난주 같은 시간(D+1 표만 전날 같은 시간), 한 달 = 제주 최근 같은 유형일 4일 평균.
- 성적 정의는 육지 `smp_forecast_app/src/final_metrics.py`와 같다 (`JF1_final_metrics.csv`).

## 2. 재현·운영 방법

### 처음부터 다시 만들 때 (루트에서, 순서대로)
```
# 1) 자료 (매일 수집 명령은 2.3절)
python -m smp_forecast_app.src.jz_features                 # 피처 표 H=1~7 (5분 실적 포함, 약 10분)
# 2) 일주일 후보 (오래 걸림: Chronos·신경망 수 시간, 이미 결과가 있으면 건너뜀)
python -m smp_forecast_app.src.jz_chronos --hist jc2s jc2sx  # 2023~ 과거 예측 (잔차 보정·급락 피처용)
python -m smp_forecast_app.src.jz_chronos jc2s jc2sx jc2 jc2x jbolt
python -m smp_forecast_app.src.jz_tab base jlgb jlgbl1 ...   # 표 모델 (docstring 참고)
python -m smp_forecast_app.src.jz_seq jlstm jgru jcnn jtransformer
python -m smp_forecast_app.src.jz_resid                     # 잔차 보정 24종 (약 50분/묶음 2개)
python -m smp_forecast_app.src.jz_ens                       # 선택·범위·결과 파일 (2026 채점은 --score2026, 이미 함)
# 3) 급락
python -m drop_classifier.src.jeju_zoo                      # 195개 비교 (캐시 없으면 약 25분, TabPFN 느림)
python -m drop_classifier.src.jeju_drop                     # J_zoo_pick 모델로 문턱·확률·drop_badge_제주.csv
# 4) 한 달 · 성적표
python -m smp_forecast_app.src.jz_month
python -m smp_forecast_app.src.jz_final_metrics --score2026
```
- TabPFN·Chronos는 `HF_HUB_OFFLINE=1`로 실행 (가중치는 이미 받아 둠). 한글 출력이 깨지면 `PYTHONIOENCODING=utf-8`.
- `--score2026`은 **이미 한 번 실행했다.** 다시 실행해도 같은 숫자가 나와야 정상이며(결과 재현), 그 숫자를 보고 무언가를 바꾸면 안 된다.

### 운영 함수 (`jz_ops.py`) — 과제2 채팅이 `ops.py`에 연결함 (2026-10-25, [OPS.md](OPS.md) 제주 절)
| 함수 | 반환 | 호출 순서·주의 |
|---|---|---|
| `weekly(bases)` | 시간별 `[base_date, H, date, hour, y, pred, lo, hi, offday]` | **육지 weekly 다음.** 육지 운영 기록 `ops/hourly_log.csv`의 같은 기준일 `pred`를 읽음. 범위용 제주 Chronos 분위수는 기준일마다 새로 계산. 기록 `jeju/ops/jwz_log.csv` |
| `drops(bases)` | `[base_date, date, grade, pred_min, prob]` (기준일 I → 내일 I+1) | 제주 Chronos H=1을 그날 새로 계산. 5분 실적은 기준일 14:25까지 필요 → **15:30 운영 전에 `kpx_jeju_sukub` 수집** |
| `monthly(bases)` | 일별 한 달 (`JMZ_predictions_daily.csv` 형식) | **육지 monthly 다음.** 육지 `ops/daily_log.csv`의 같은 기준일 행을 읽음 |
| `train()` | 잔차 보정(H별, 실적 전부로 학습) → `models/jz_resid.pkl` | 매주 일요일 육지 train과 함께 권장 |
| `train_drop()` | 급락 학습 자료(2024-01~2025-12, 731일) → `models/jz_drop.pkl` | 2026 시험과 같은 '고정' 모델. **급락 모델을 바꿀 때만** 다시 실행 (2026-10-25 S5 KNN으로 재학습함) |

- 피처가 날짜에 고정돼 늦게 실행해도 같은 값.
- 백테스트 대조:
  - 급락: 같은 값. 단, 백테스트 파일의 마지막 날은 제주 Chronos 예측이 아직 없어 중앙값으로 채워짐(운영 값이 맞음).
  - 일주일: 점예측 차이 평균 0.1~0.9원 (운영 잔차 모델이 최근 실적까지 학습). 범위 경계는 같음.
  - 한 달: 육지 운영 기록 기준으로 계산되므로 백테스트 파일의 최근 며칠(육지 백테스트 파일이 비어 있는 날)은 빈칸.
- 시험 실행: `SMP_NO_PUSH=1 python -m smp_forecast_app.src.jz_ops 2026-10-21 2026-10-22` (운영 기록 `data/processed/smp_forecast_app/ops/`는 건드리지 않음).

### 매일 수집 명령 (과제2 채팅이 `ops.py`에 추가)
```
python -m common.collect.kma_regional_fcst {3일 전 YYYYMM} {오늘 YYYYMM} jeju
python -m common.collect.openmeteo_prevruns {5일 전 YYYY-MM-DD} {오늘+3일 YYYY-MM-DD} jeju
python -m common.collect.openmeteo_prevruns {5일 전 YYYY-MM-DD} {오늘+8일 YYYY-MM-DD} jeju_ext

```
- openmeteo 수집은 시작·끝 날짜가 같은 파일이 있으면 건너뛰므로 매일 날짜가 바뀌어야 새로 받는다(육지와 같은 방식).
- `kpx_jeju_sukub`는 data.go.kr 개발계정 하루 100회 한도. 호출 1회 = 하루치(288행)라 매일 3~4회면 충분. 한도를 넘으면 멈추고 다음 실행에서 이어 받음.
- 제주 SMP·수요예측은 기존 `smp_forecast` 수집에 이미 들어 있다.

### 확인된 사실 (추측 말고 이것부터)
- **구역예보에는 풍속이 없다.** 인수 메모가 "풍속등급"으로 본 11번째 열은 API 도움말상 풍향 경향(1 "-", 2 "후")이고 실제로 모두 1. 쓸 수 있는 값: 풍향(16방위)·기온·강수확률·하늘·강수유무 (2026-10-23 help=1로 확인).
- **풍속 예보는 Open-Meteo에서만.** 10m는 세 모델 모두, 100m는 ECMWF(2024-03-08~)·GFS만. 2025년부터 결측 거의 없음.
- 동네예보 제주(184)는 D-1 **17시** 발표분이라 15시 판단에 못 씀.
- 구역예보 원문 월 경계에서 두 레코드가 한 줄로 붙은 경우가 있다. 제주 로더는 레코드 단위로 다시 나눈다. 육지 로더에도 같은 현상이 있지만 H=0 구간이라 육지 피처 영향 없음(수정 안 함).

## 4. 일주일 예측 (D+1~D+7, 시간별) + 80% 범위

### 4.1 모델
**최종 = 육지 일주일 최종 예측 + 0.25 × 제주 잔차 예측** (`JWZ_choice.json`)

### 6.1 문제 정의
- 대상: 내일 제주 11~15시 최저 SMP < 30원 (과제1 [07_제주_레이블링.md](../../drop_classifier/docs/07_제주_레이블링.md)). 레이블 `data/processed/drop_classifier/daily_label_제주.csv`.
- 급락일: 2024년 20일, 2025년 60일, 2026년(~10/23, 채점 대상) 54일. 육지(4.6%)보다 훨씬 잦음(약 14%).
- 2024 이후 육지 급락일은 모두 제주도 급락. 그러나 **제주만 급락한 날**이 많다(평일·낮은 제주 수요·맑음·강풍) → 육지 예측의 한낮 최저만으론 거의 못 가림(헛경보 265일).
- 검증(2025만): F1 = 2024 학습 → 2025 상반기, F2 = 2024~2025 상반기 학습 → 2025 하반기, 이어 붙여 채점.
- 순위(육지와 같음): 급락 90% 잡을 때 헛경보 수 → 100%일 때 헛경보 수 → PR-AUC.

### 6.2 최종 모델: S5 + KNN 분류 (`JD_choice.json`)
- **KNN 분류**: 피처를 표준화(빈 값은 학습 중앙값)한 뒤, 학습 기간(2024-01~2025-12, 731일)에서 내일과 가장 비슷한 25일을 찾아 **거리 가중 급락 비율**을 점수로 냄. 설명 문장으로 바꾸기 쉬움("비슷했던 과거 25일 중 ○일이 급락").
- **피처 S5 = 63개** (모두 D-1 15시에 알 수 있는 값):

| 묶음 | 피처 |
|---|---|
| 달력 (12) | 휴무일, 요일 유형, 요일, 연휴 길이·순서, 명절, 노동절, 전날·다음날 휴무, 월(sin·cos), 추세 |
| 제주 SMP 지난 값 (11) | 전날 한낮 최저·최저·평균, 같은 유형일 한낮 최저, 28일 평균, 최근 7일 한낮 최저, 최근 14·28일 급락 수, 제주만 급락 28일, 육지와 같은 가격 비율 7·28일 |
| 제주 수요예측 (3) | 전날 한낮·평균, 28일 중앙값 대비 |
| 구역예보 (6) | 오후·오전 하늘, 오후 강수확률·강수, 오후 기온, 북풍 성분 |
| Open-Meteo 제주 (6) | 한낮 일사·운량, 10m 풍속, 100m 풍속(하루·한낮·밤) |
| 육지 정보 (11) | 육지 전날 한낮 최저, 같은 유형일 12시, 육지 하늘·일사 예보, 주간 최대수요 전망·상대값, LNG·석탄 연료비, 태양광 설비, 육지 일주일 예측·Chronos의 내일 한낮 최저 |
| 제주 예측 (2) | 제주 Chronos-2 small(육지 공변량)의 내일 한낮 최저·하위 10% |
| **5분 계통 실적 (12)** | 3절 참고 |

- 문턱(2024 학습 → 2025 예측으로 정함): **주의 = 점수 0.155 이상** (2025 급락 54/60 포착, 헛경보 72일), **강한 경보 = 0.194 이상** (2025: 97일 중 48일 적중, 정밀도 약 50%).
- 확률 = 로지스틱 보정 P = 1/(1+exp(−(−4.360 + 16.318 × 점수))). 주의 문턱 ≈ 14%, 강한 경보 문턱 ≈ 23%. ⚠ 23%는 **문턱 경계**의 확률이고 강한 경보 구간 전체 적중률은 약 50%.

- 웹 문구 (제주 급등 자리): "제주 급등 경보는 제공하지 않습니다. 2025년 이후 제주 급등은 연 6~7회뿐이고 대부분 당일 사정에 따른 단발성이라 전날 정보로 미리 알 수 없었습니다. 육지와 함께 오르는 날은 육지 급등 경보를 참고하세요."
- 발표 표현: "제주 급등은 2025년 이후 연 7회 수준이고 대부분 당일 사정에 따른 단발성이라, 전날 15시 정보로는 예측할 수 없음을 확인했다 (모델을 만들어 2025·2026에서 무작위 수준임을 확인)."
- 다시 볼 조건: 급등이 다시 늘거나, 제주 발전기 정지·연계선(HVDC) 운전 정보 같은 새 자료가 생길 때.
