# 과제3 예측 근거 문장 (R5) — 형식·운영

> 범위: 육지 **내일 급락 경보**(LSTM + LightGBM 평균)와 **내일 급등 경보**(부호 고정 + 스플라인 + 그루터기). 일주일·한 달은 고도화 뒤.
> 코드: `src/reason_drop.py`, `src/reason_surge.py`, `src/reason_web.py` (모델 코드·결과는 읽기만).

## 1. 웹에 붙이는 파일 — `outputs/tables/R5_why_육지.json`

웹 `data.ts`의 `why` 자리와 같은 모양이다. 총괄 `export_web.py`에서 `land["why"] = json` (또는 `meta` 뺀 `drop`·`surge`)만 넣으면 된다.

```json
{
 "meta": {"made": "2026-11-01 12:11", "region": "육지", "기준": {...}, "표시 문턱": {...}, "dir": "..."},
 "drop":  {"2026-01-18": [{"t": "지난 휴일(1/17) 한낮 가격이 0원까지 내려갔습니다", "dir": "up"}, ...]},
 "surge": {"2026-11-01": [{"t": "내일은 휴일이라 전력 수요가 적어 급등 경보를 내지 않습니다", "dir": "down"}]}
}
```

- 열쇠 = **대상일**(경보 카드의 날짜). 문장 = 판단일 기준 말투("오늘" = 판단일, "내일" = 대상일).
- 줄 수 = **0~3이 아니라 1~3**. 확실한 근거만 내고, 없으면 고정 문장 한 줄:
  - `{"t": "평소와 다른 급락(급등) 위험 신호가 없습니다", "dir": "none"}`
- `dir`: `up` = 위험을 높임(▲), `down` = 낮춤(▼), **`none` = 근거 없음** (새 값). 줄 순서 = 판정과 같은 방향 먼저, 그다음 기여 큰 순.
- 기간: 급락 2025-01-01 ~ 내일, 급등 2026-01-01 ~ 내일 (급등 2025는 저장된 모델이 2023~2025 학습이라 학습 구간 안 → 내지 않음).

## 2. 계산용 긴 표 — `outputs/tables/R5_reason_육지.csv`

| 열 | 뜻 |
|---|---|
| base_date, date | 판단일, 대상일 |
| kind | drop / surge |
| grade, score | 경보 등급·점수 (R1·R4 백테스트와 같음 — 급락 656일·급등 302일 등급 불일치 0) |
| rank | 줄 순서 1~3, 근거 없음 = 0 |
| t, dir | 문장, 방향 (위와 같음) |
| group, feature | 근거 묶음(현업 말), 문장 틀을 고른 피처 |
| contrib, unit | 묶음 기여. 급락 = 예상 한낮 최저 변화(원, 음수 = 위험↑), 급등 = 세 확률 평균 변화(양수 = 위험↑) |

## 3. 운영

- 15:30 경보 예측(`ops_drop.predict_team`, `ops_surge.predict`) **뒤에** `python -m smp_forecast_app.src.reason_web --ops [판단일, 기본 오늘]` → 다음 날 하루를 계산해 두 파일에서 그 날만 바꿔 끼움. **약 40초** (급락 LSTM을 같은 설정으로 다시 학습 ~30초, 급등 ~10초).

- 전체 다시 만들기(재학습·문턱 변경 뒤): `python -m smp_forecast_app.src.reason_web` (약 70초).

## 4. 계산 방법 (요약)

| 경보 | 방법 | 비교 기준 |
|---|---|---|
| 급락 | LightGBM TreeSHAP + LSTM 묶음 가리기 Shapley(7묶음, 128조합, 시드 5개) → 각 ÷ 2 | 평소 날 (학습 구간 평균) |
| 급등 | 세 모델 모두 로짓이 피처별 항의 합 → 정확 분해, 확률로 옮겨 ÷ 3 | 평소 평일 (휴일은 모델이 0점) |

- 기여의 합 + 기준 = 모델 점수 (코드에서 매번 확인). 묶음 기여가 급락 10원·급등 0.05 이상일 때만 문장. 문장 틀은 묶음 안에서 기여가 가장 큰 피처로 고르고, 실제 값이 방향과 어긋나면 그 틀은 건너뜀.
- 묶음: 급락 = 지난 같은 유형 날 · 최근 흐름 · 전력 수요 · 날씨 예보 · 달력 · 태양광 설비 · 연료비, 급등 = 오늘 가격 · 최근 최고 가격 · 가격 수준 변화 · 최근 급등 · 전력 수요 · 기온 · 흐림·비 · 달력.
