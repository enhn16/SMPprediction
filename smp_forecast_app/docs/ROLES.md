## 2. 2단 운용 설계 (1차 15시 · 2차 21시)

**공표 사실 (판정서 v1.2)**: 내일 SMP와 내일 수요예측은 **같은 시각**에 공표된다(따로 먼저 나오는 경로 없음). 평일 19~20시(목·금 20시, 월·수 19시 전후, 화는 23시 지연·미공표 가능), 토·일은 14시 이전. 21시 확보율 평일 88%.

→ 따라서 2차(21시)에서 **내일은 대부분 '예측'이 아니라 '공표값으로 확정'**이고, 2차의 실익은 **2~7일 뒤를 내일 공표값까지 넣어 다시 예측**하는 데 있다.

| 예측 | 1차 (15시, 근사) | 2차 (21시, 확정) |
|---|---|---|
| **내일 급락 경보** | 지금 모델 (육지 Ridge+EBM+RF, 제주 KNN) | ① 내일 SMP 공표됨 → **공표 한낮 최저로 확정 판정** (급락/아님) ② 미공표(화 등) → **2차 모델**: 내일 수요예측 확정치를 넣은 판별 (현업 학생 모델과 같은 입력). 수요예측도 미공표면 1차 유지, 23:30 재시도 |
| **내일 시간별 가격** | 일주일 모델 D+1 | 공표 SMP (이미 웹에 표시) |
| **2~7일 뒤 가격** (일주일) | 지금 모델 | **2차 모델**: 내일 공표 SMP·수요예측까지 넣어 D+2~D+7 재예측 + 80% 범위 |
| **한 달** | 지금 모델 | 바꾸지 않음 (하루 차이 효과 작음) |
| **급등 경보** | 급등 담당 1차 모델 | 급락과 같은 방식 (공표 확정 / 미공표 시 2차 모델) |

- **2차 모델 평가**: 2025로만 고르고, 2026(2026-01-01 ~ 최신)은 **한 번 채점 = '2차(21시) 1차 시험'**으로 표기. 1차와 같은 표준 지표.
- **'21시 판단' 백테스트의 정보 기준**: 기준일 I의 21시에 알 수 있는 값 = 1차 정보 + **I+1일 공표 SMP·수요예측**(그날 21시까지 공표된 경우만. 과거 공표 시각 기록이 없으므로 **화요일 판단분은 미공표로 보수 처리**하는 등 규칙을 정해 문서에 남길 것) + 21시 전 발표 날씨(17시 단기예보 가능).
- 운영 시각 (총괄): 15:30 1차 · **21:30 2차** · 23:30 재시도(화요일 지연 대비). 늦게 켜지면 따라잡기 (지금 방식 유지).

## 4. 공통 약속 (총괄이 웹에 붙이는 형식)

### 4.1 경보 (급락·급등) — 계통·단계별
- **백테스트 결과**: `{담당 폴더}/{kind}_{계통}_{stage}.csv` (kind = drop|surge, stage = 15h|21h)
  - 열: `base_date, date, stage, grade, prob, score, label` — `grade` ∈ {없음, 주의, 경보}, `prob` = 보정 확률(0~1), `score` = 모델 점수(예상 한낮 최저 등, 없으면 빈칸), `label` = 실제(1/0, 미확정 빈칸). 2025-01-01부터.
- **운영 함수**: `predict(bases, stage) -> DataFrame` (위 열, label 제외). 판단일까지 자료만. 21h는 4.4 규칙.
- **설정**: `{kind}_choice_{계통}_{stage}.json` — 모델·피처·문턱(주의·경보)·확률식·선택 절차.
- **성적표**: `{kind}_score_{계통}_{stage}.csv` — 구간(2025 표본 밖 / 2026 시험) × 경보(주의 이상 / 경보) × {일수, 급락(급등)일, 적중, 놓침, 헛경보, 재현율, 정밀도, 헛경보율, ROC-AUC, PR-AUC} + **헛경보@재현율80%, 헛경보@재현율90%**.

### 4.2 가격 (시간별 D+1~D+7)
- 백테스트: `WZ_predictions_hourly.csv`와 같은 열 + `stage` (`base_date, H, date, hour, y, pred, lo, hi, offday, stage`).
- 운영 함수: `weekly(bases, stage)` → 같은 열. 성적표: `final_metrics.py`와 같은 표준 지표(MAE·RMSE·MAPE·rMAE·편향·포함률·하한 아래·상한 위·평균 폭·구간점수) × 구간·지평.

### 4.3 이름·표기
- 경보 단계: **없음(낮음) / 주의 / 경보**. 기존 산출물의 `강한 경보`는 웹이 `경보`로 읽으므로 당장 바꾸지 않아도 됨. 새 산출물은 `경보`.
- 예측 이름: **내일 급락 경보 · 내일 급등 경보 · 일주일 예측 · 한 달 예측**, 단계: **1차(15시) · 2차(21시)**.
- 재현율 = 실제 급락(급등)일 중 미리 경보한 비율. 정밀도 = 경보한 날 중 실제 급락(급등) 비율. "헛경보@재현율80%" = 실제 급락의 80%를 잡도록 문턱을 내렸을 때 헛경보 일수.

### 4.4 21시 판단 정보 규칙 (2차 백테스트 공통)
- 기준일 I의 21시 = 1차 정보 + I+1 공표 SMP·수요예측(공표 가정 규칙은 2절) + I일 17시 단기예보(필요 시).
- **화요일 판단(수요일 대상)**은 미공표로 보고 따로 성적을 낸다 (판정서: 화 23시 지연·미공표).
- 2025로만 선택, 2026 한 번 채점. 1차와 같은 날짜·같은 지표로 나란히 비교.

### 4.5 보고
- 단계마다 결과 요약 → 사용자 확인 → 다음 단계 (루트 규칙). 결정은 자기 문서의 결정 기록에.
- 끝나면 **총괄에게 넘길 것**: 산출 파일 경로, 운영 함수 이름·호출 순서·소요 시간, 성적 요약 3줄, 발표 때 지킬 표현.
