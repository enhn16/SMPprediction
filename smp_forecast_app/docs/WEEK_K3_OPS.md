# 일주일 예측 K3 운영 안내 (육지, 1~7일 뒤 시간별 SMP)

> 대상: 이 모델을 직접 돌려 볼 현업 담당자. 2026-11-03 작성 (R3 일주일 예측).
> 모델을 고른 과정과 근거는 [WEEK_V3.md](WEEK_V3.md) ⑥·⑦, 설정 원본은 `outputs/tables/WZ3_K3_choice.json`.

## 1. 한눈에

| 항목 | 내용 |
|---|---|
| 예측하는 것 | 기준일 I의 15시에, I+1일 ~ I+7일 **시간별 육지 SMP**(168개 값)와 **80% 범위**(하한·상한) |
| 모델 | 평일 시간은 **미세조정한 Chronos-2 small**, 휴무일 시간은 **날씨·수요전망을 넣은 Chronos-2 small**. 둘 다 LightGBM으로 남은 오차를 절반만큼 보정 |
| 매일 할 일 | 자료 수집 → `weekly([오늘])` 한 번 (**약 1분**, CPU 노트북) |

| 매년 할 일 | 12월 31일에 Chronos 미세조정 1회 (**약 1시간**) |
| 성적 (MAE, 원/kWh) | 2025 검증 **8.95** (같은 시간끼리 비교한 7~12월: K3 8.96 · 지금 운영 모델 9.21) · 2026 시험(1/1~10/18) **9.65** (지금 운영 모델 9.66) |
| 80% 범위 포함률 | 2025 79.7% · 2026 78.7% (지금 운영 모델 2025 7~12월 77.5% · 2026 76.9%) |

## 2. 모델 구성

```
기준일 I 15시까지 알려진 자료
 ├─ 시간별 SMP 최근 2,048시간 ──┬─▶ ① Chronos-2 small 미세조정판 (달력 공변량)        → 평일 시간의 기본 예측
 │                              ├─▶ ② Chronos-2 small 제로샷 (달력 + 주간 최대부하·
 │                              │      하늘상태·강수확률·LNG·유연탄 연료비 공변량)      → 휴무일 시간의 기본 예측
 │                              └─▶ ③ Chronos-2 대형판 제로샷 (달력 공변량)              → 범위용 분위수 0.1·0.9
 ├─ 날씨 예보·주간 수요전망·연료비·설비용량·달력 ─▶ ④ 오차 보정 LightGBM (평일용·휴무일용 × 1~7일 뒤 = 14개)
 │
 ▼
 점예측 = 기본 예측(평일 ①, 휴무일 ②) + 0.5 × ④가 예측한 오차
 80% 범위 = ③의 0.1·0.9 분위수를 점예측만큼 옮긴 뒤, 직전 365일 실제 오차로 넓히거나 좁힘
```

| 부분 | 설정 | 학습 |
|---|---|---|
| ① 평일 Chronos | `autogluon/chronos-2-small` **전체 미세조정**: 학습률 1e-6, 500단계, 배치 32, 과거 2,048시간, 예측 168시간, 공변량 = 휴무일·요일유형(평일·주말·공휴일·연휴)·명절, 시드 42 | **1년에 한 번**. 2022-01-01 ~ 12-31 SMP로 학습한 판 `ft{연도}f` |
| ② 휴무일 Chronos | `autogluon/chronos-2-small` 학습 없이 사용, 공변량 = 달력 3개 + `kpx_peak`(주간 최대부하 전망) · `rf_sky_pm`·`rf_pop_pm`(오후 하늘상태·강수확률 예보) · `fc_lng`·`fc_coal`(연료비단가) | 없음 |
| ③ 범위용 Chronos | `amazon/chronos-2` 학습 없이 사용, 달력 공변량 | 없음 |
| ④ 오차 보정 | LightGBM(절대오차 L1, 400그루, 잎 15, 학습률 0.03, 최소 표본 200). 피처 25개: 시간·요일·휴무일·앞뒤 휴무일·명절, 연료비, 태양광 설비용량, 주간 최대부하(값·상대값·전날 수요예측 대비), 하늘상태·강수확률·기온 예보, Open-Meteo 일사·운량(1일 뒤만), Chronos 예측값·분위수 폭·전날·지난주 같은 시간·28일 평균과의 차이 | **매월**. 2023-01-01 ~ 그달 1일 전까지(1일 뒤 모델 기준, H일 뒤 모델은 H−1일 더 앞까지)의 실제 오차 |
| 범위 | 대칭 보정(A1): 시간대묶음(밤 1~8시·오전 9~10시·한낮 11~15시·오후 16~17시·저녁 18~24시) × 휴무일 여부 칸마다 직전 365일 `max(하한−실적, 실적−상한)`의 80% 분위수만큼 넓힘. 하한은 0원 아래로 내리지 않음 | 매일 (이력만 씀) |

- **0.5(보정 비율 λ)**는 2024~2025 자료로 정했다 (0, 0.25, 0.5, 0.75, 1 중 MAE가 가장 작은 값).
- **휴무일** = 토·일·공휴일·대체공휴일·임시공휴일·선거일·노동절(2026~)·제헌절(2026~). 천문연구원 특일정보로 만든 공용 달력(`common.calendar`)을 쓴다.
- **미세조정판 고르는 규칙**: 마감 Y-12-31 판은 기준일 Y-12-31부터 다음 판이 나올 때까지 쓴다. 마감 뒤 실적이 학습에 들어가지 않도록 기준일로 고른다.

## 3. 판단 시각 15시에 쓰는 자료 (팀 공통 13종 중 9종)

| 자료 | 쓰는 범위 | 쓰는 곳 |
|---|---|---|
| 시간별 SMP (육지) | 기준일 I의 24시까지 (I일 SMP는 전날 저녁 공표) | ①②③ 입력, ④ 피처 |
| 하루전 수요예측 | I일분까지 (I+1일분은 19시 이후 공표라 안 씀) | ④ 주간 최대부하 ÷ 전날 수요예측 |
| 특일정보 | 미리 정해진 달력 | ①②③ 공변량, ④ |
| 주간 전력수요전망 | I−1일까지 게시분 | ②, ④ |
| 연료비단가 (LNG·유연탄) | M월 값을 M+2월 1일부터 | ②, ④ |
| 시장참여 설비용량 (태양광) | M월 값을 M+2월 1일부터 | ④ |
| 단기 구역별 육상예보 | I일 11시 발표분 (없으면 05시), 1~3일 뒤 | ②, ④ |
| 중기 육상예보 | I일 06시 발표분, 4일 뒤부터 | ②, ④ |
| Open-Meteo 과거 실행 예보 | 2일 이상 전에 실행된 예보, 1일 뒤만 | ④ |

쓰지 않는 자료: 내일(I+1일분) 수요예측·내일 SMP (15시에 공표 전), 제주 5분 실적, 오늘전력수급현황, 지역별 태양광 발전량.
**내일 SMP가 공표되면(평일 19~20시, 늦으면 23시) 웹은 1일 뒤 예측 대신 공표값을 보여 준다.** 2차 재예측은 하지 않는다.

## 4. 준비

### PC·프로그램
- Windows 10/11, CPU만으로 충분 (GPU 불필요). 메모리 16GB 노트북에서 검증. **미세조정할 때는 다른 프로그램을 닫는다** (메모리가 모자라면 학습이 중간에 멈춘 적이 있음).
- Python 3.12. 검증한 버전: `chronos-forecasting 2.3.2`, `torch 2.14.0 (cpu)`, `transformers 5.17.0`, `peft 0.21.2`, `accelerate 1.15.0`, `lightgbm 4.7.0`, `pandas 2.3.3`, `numpy 2.3.3`, `scikit-learn 1.9.1`, `joblib 1.6.0`, `python-dotenv 1.2.4`.
- 기초모델은 처음 한 번 Hugging Face에서 내려받는다: `autogluon/chronos-2-small` (약 107MB), `amazon/chronos-2` (약 456MB). 그 뒤에는 `HF_HUB_OFFLINE=1`로 오프라인 실행이 가능하다.
- API 키(공공데이터포털·기상청 API허브)는 `.env`에 둔다 (코드에 적지 않음).

## 5. 처음 한 번

1. 자료를 2022-01부터 모은다 (팀 공통 자료 수집기 `common.collect.*`, 기존 운영과 같음).
2. 미세조정판이 없으면 만든다: `python -m smp_forecast_app.src.wz3_ops --finetune 2025` (약 1시간, 마감 2025-12-31 → 2026 기준일용).
3. 구성값 이력과 백테스트를 만든다: `python -m smp_forecast_app.src.wz3_ops --backtest` (약 10분). 과거 Chronos 예측 파일(`wz3/chronos/`)이 필요하다. `k3_parts.csv.gz`가 이미 있으면 운영 이력을 지키려고 덮어쓰지 않는다.
4. 밀린 기준일을 채운다: `python -m smp_forecast_app.src.wz3_ops 2026-10-18 2026-10-19 …` (기준일 하나에 수 초, 2026-11-03까지 채워 둠).

## 6. 매일 (15:30 이후)

1. 자료 수집 (기존 운영 `ops daily`의 수집 단계와 같음: SMP·수요예측, 단기·중기 예보, Open-Meteo, 주간 수요전망, 월초에는 연료비·설비용량).
2. 예측:
   ```python
   from smp_forecast_app.src import wz3_ops
   r = wz3_ops.weekly(["2026-11-04"])        # 기준일 = 오늘. 여러 날을 한 번에 넣어도 됨 (밀린 날 따라잡기)
   ```
   명령줄로는 `python -m smp_forecast_app.src.wz3_ops` (기준일을 안 주면 최신 SMP 날짜).
3. 결과 `r` (기준일 하나 = 168행):

| 열 | 뜻 |
|---|---|
| `base_date`, `H`, `date`, `hour` | 기준일, 며칠 뒤(1~7), 대상일, 시각(**1~24시**) |
| `pred`, `lo`, `hi` | 점예측, 80% 범위 하한·상한 (원/kWh) |
| `y` | 실적 (아직 없으면 빈칸) |
| `offday`, `stage` | 대상일 휴무일 여부, `15h` |
| `ckpt`, `c`, `rhat` | 쓴 미세조정판, 기본 예측(평일 ①·휴무일 ②), 오차 보정값 (점예측 = c + 0.5 × rhat) |
| `ft_pred`, `ext_pred`, `c2_qlo`, `c2_qhi` | ①·② 중앙값, ③ 분위수 0.1·0.9 (점검용) |

- 같은 기준일을 다시 돌리면 이력의 그 행을 새 값으로 바꾼다. 늦게 돌려도 15시 판단 자료만 쓰므로 예측 내용은 같다 (단, 그사이 원천 자료가 고쳐졌으면 조금 다를 수 있음).
- 소요 시간: 기준일 1개 약 1분 (피처 표 만들기 약 25초 + Chronos 3개 약 40초). 그달 첫 실행은 오차 보정 학습 15초가 더 든다. 17개 기준일을 한 번에 넣으면 약 2분.

## 7. 매월 — 자동

`weekly`가 대상일의 달에 맞는 `resid_{YYYY-MM}.pkl`이 없으면 스스로 학습한다 (백테스트와 같은 규칙: 2023-01-01 ~ 그달 1일 − (H−1)일 전 실적). 따로 돌리려면 `python -m smp_forecast_app.src.wz3_ops --train 2026-12`.

## 8. 매년 — 12월 31일 미세조정 1회

```
python -m smp_forecast_app.src.wz3_ops --finetune 2026      # 마감 2026-12-31 판 ft2026f, 약 1시간
```
- 12월 31일 오전에 돌리면 그날 15시 예측부터 새 판을 쓴다 (12/31 SMP는 12/30 저녁에 공표되므로 오전에 학습 가능).
- 새 판이 아직 없으면 `weekly`가 **직전 판으로 대신 예측하고 경고를 출력**한다 (`[주의] 기준일 …: ft2026f 판이 없어 ft2025f로 대신함`). 예측은 계속 나오므로 1월 초까지 학습해도 된다.
- 분기마다 다시 학습하는 것도 시험했지만 2025 MAE 차이가 0.004원뿐이어서 1년 1회로 정했다 (WEEK_V3.md ⑦).

## 9. 점검·문제 해결

| 증상 | 원인·조치 |
|---|---|
| `[주의] 피처가 없는 N행은 잔차 보정 0` | 그날 예보·전망 수집이 빠짐 → 수집 후 같은 기준일을 다시 실행 |
| `[주의] … 판이 없어 … 대신함` | 그해 미세조정 전 → 8절 |
| `[주의] SMP가 …까지라 그 뒤 기준일은 건너뜀` | 기준일 SMP(전날 저녁 공표)가 아직 없음 → SMP 수집 확인 후 다시 실행 |
| 미세조정이 중간에 멈춤·PC가 매우 느림 | 메모리 부족 → 다른 프로그램 종료, 스레드 제한(`OMP_NUM_THREADS=8`), 낮은 우선순위로 실행. 노트북은 충전기를 꽂고 절전을 끈다 |
| 매일 확인할 숫자 | 기준일당 168행, `lo ≤ pred ≤ hi`, `ckpt`가 그해 판인지, 최근 4주 1일 뒤 MAE (2026 평균 8.2원) |

## 10. 성적과 한계

공식 성적 기간·지표는 팀 비교표와 같다 (`team_scorecard` 지표, 지금 운영 모델과 같은 날짜·시간끼리). 2025는 고르는 데 쓴 기간, 2026은 마지막에 한 번 채점한 기간이다. 지금 운영 모델의 백테스트가 2025-07-01부터라 2025 비교는 7~12월이다.

| 구간 | 2025 7~12월 MAE: 지금 → K3 | 2026 MAE: 지금 → K3 | 2026 포함률: 지금 → K3 | 2026 구간점수: 지금 → K3 |
|---|---|---|---|---|
| 전체 | 9.21 → **8.96** | 9.66 → **9.65** | 76.9% → 78.7% | 50.86 → 50.97 |
| 평일 | 8.11 → 7.90 | 8.76 → 8.74 | 76.4% → 78.0% | 45.09 → 45.33 |
| 휴무일 | 11.52 → 11.20 | 11.42 → 11.42 | 78.0% → 80.2% | 62.06 → 61.92 |
