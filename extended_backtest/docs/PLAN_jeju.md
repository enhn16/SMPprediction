## 결정 기록
- 2026-11-06 **시험 = 2025-01-01 ~ 2026-10-31 (22개월)**, 학습 2020 ~ 2024 (부서 참고안, 1104 판정기준 문서 4번). 2026은 「2차 시험」 표시. 2025-07 ~ 부분은 같은 예측에서 잘라 육지와 비교용으로 참고 표시.
  - 근거: 제주 0원은 2024년부터라 시험 사건 108구간(80%), 봄·가을 두 번씩 포함.
  - 2025는 운영 제주 모델 선택 때 검증 해로 쓴 해다(표 아래 명시).
- 2026-11-06 **매달 다시 학습** (그 전달 말까지 자료). 예측은 2024-01부터 모든 달 '앞으로만'.
- 2026-11-06 **2단계 설계** (사용자 위임):
  - 2024년 전에는 순부하 200MW 이하에서도 0원 없음(SMP 66~188원) → 같은 '재생에너지 잉여'가 출력제어로 처리됨. 제주 출력제어 시간별 기록(`data/raw/제주 태양광·풍력 출력제어*.csv`, 2021-01 ~ 2024-06-03)을 **레이블로만** 쓴다(사후 정보라 피처 금지).
  - 1단계 '잉여일' = 출력제어 또는 SMP ≤ 0원. 2021-01 ~ 2024-05 실제 수요·태양광·풍력(5분 실적)으로 학습, 예측 땐 전날 15시 전망값을 넣는다. 2020은 출력제어 기록이 없어(파일 시작 2021-01) 1단계 레이블에서 뺀다 → 흐름 분석·평소 수준 계산에만 사용.
  - 2단계 '0원일' = 2024-01 ~ 전달까지 학습, 1단계 점수 + 전망 순부하(낮·새벽) + 최근 0원 + 육지 가격 + 달력.
  - 출력제어 2024-06 이후 기록은 없음(사용자 확인).
- 2026-11-06 0원 시작 시점: 첫 0원 2024-02-10(설 연휴). 재생에너지 입찰제·실시간시장 시범사업은 2024-03 모의운영(보도) → 2024-06-01 본격 운영(기후솔루션). 첫 0원은 본격 운영보다 앞서므로 '제도 = 0원 시작' 단정은 하지 않는다. 2024년 0원 20일 중 17일이 6월 이후.
