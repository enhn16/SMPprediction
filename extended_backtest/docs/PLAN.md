  1. 매달, 그 전달 말까지의 자료(2020-01부터 전부)로 학습해서 그달을 예측한다 (2024-01 ~ 2026-10, 34번).
  2. 그달의 주의·경보 문턱은 바로 앞 12개월의 '앞으로만 예측' 결과로 정한다 (규칙은 운영과 같음: 주의 = 재현율 80%, 경보 = 정밀도 50%·적중 3일 이상).
- 2024년은 첫 문턱용 연습 구간(채점 안 함). 2025 초반 문턱은 급락 8일(2024)로 정해져 거칠다 → 틀린 날 분석에서 '학습 기간에 급락이 적었던 영향'으로 따로 보인다.
- 급락·급등 모두 **전체 날** 학습·판정. 급등의 '휴무일 경보 없음' 규칙은 뺀다.
- 경과: ① 시험 직전 한 번 자른 모델로 문턱 → 폐기(그 모델은 급락 6구간만 봄). ② 시험 2025-07~ → 매달 다시 학습이면 앞당겨도 분리가 유지되어 2025-01~로 확정.

## 발표 표 형식 (판정기준 v1.1 6절, 2026-11-06 다시 읽음)
- 확률 모델은 **주의·경보 두 단계** 전제 (성공 = 경보, 부분 = 주의만, 실패 = 없음). 단계 하나로 줄이지 않는다.
- 표 1: 구간 단위, 칸마다 건수(비율), 휴일/평일. 하루 경보는 그날 모든 구간에 적용.
- 표 2: 헛경보 = 날짜 단위, 휴일/평일/계, 주의·경보 나눠 표시.
- 혼동행렬(선택, '더 좋다'): 날짜 단위 3줄(경보·주의·없음) × 2열(사건 있음·없음) — 표 1·2와 숫자가 이어짐.
- 표 아래: 시험 기간·학습 기간·예측 시점(전날 15시), 2026 = 2차 시험. 급등 34% 해석, 평일 급락 따로.
- 회사도 같은 기준으로 운영 예측(2026-08-11~)을 채점·발표 → 같은 형식으로 맞춘다.

## 틀린 날 분석 원칙 (2026-11-06, 제주 채팅 발견·사용자 동의)
- SMP는 전날 오후 전력거래소의 수요·태양광·풍력 **전망**으로 확정 → 실제 날씨는 가격 원인이 아니다.
- 놓친 날은 "가격 원인(거래소 전날 전망)"과 "모델이 놓친 원인(우리 예보가 거래소 전망과 다름)"으로 나눈다. 거래소 전망 근거 = 수집 중인 D일 하루전 수요예측(15시 피처로는 못 씀).
- 육지 급락·급등 피처는 이미 전부 전날 발표 예보·전망 (실측 날씨 없음).
