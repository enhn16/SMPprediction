# 총괄 전달: 11/11 발표용 급락·급등 재채점 결과 (새 판정 기준)

> 웹 공식 성적(최종 모델 성적표, 2026-01-01~10-18)과 **별개 작업**이다. 웹 숫자를 바꾸지 않는다. 폴더: `extended_backtest/`.
> 자세한 결과: `docs/RESULTS.md`, 분석: `docs/ANALYSIS_NOTES.md`, 그림: `outputs/figures/F1_quarterly.png`.

## 1. 무엇을 했나
- 11/4 판정기준 v1.1로 육지 급락·급등을 다시 채점. 제주 급락은 기준이 바뀌어(0원 이하·하루 전체) 별도 채팅에서 모델을 다시 고르는 중(`docs/HANDOFF_jeju.md`).
- **사건 수는 부서 5번 표와 같다** (2020-01-29~2026-10-31): 육지 급등 284/1,199, 육지 급락 46/3 (휴일/평일). 제주 0원 이하 62/73 (부서 62/72 — 2024-12-05 13시 한 시간이 EPSIS 0원, 교육용 파일 137원인 원본 차이).
- **구간** = 기준을 넘은 시간이 하루 안에서 이어진 묶음. 끊기면 2구간. 하루 경보는 그날 모든 구간에 적용.

## 2. 방식 (발표 표 아래에 적을 것)
- 시험 2025-01-01 ~ 2026-10-31 (22개월, 2026 = 「2차 시험」). 예측 시점 전날 15시.
- 학습: 2020-01부터 **예측하는 달의 전달 말까지, 매달 다시 학습**. 문턱: **그달 바로 앞 12개월의 앞으로만 예측으로 매달 다시 정함**. 시험 구간으로 모델·문턱을 고르지 않음.
- 모델 구성은 팀 합의 그대로: 급락 = LSTM + LightGBM 평균, 급등 = 세 모델 평균(입력 40개). 급락·급등 모두 전체 날(휴무일도 경보).
- 급등은 **새 기준(+20원)으로 다시 학습한 판(B)을 대표**로, 지금 모델(옛 ×1.25 학습, A)을 비교로.
- 문턱 규칙: 주의 = 재현율 80%. 경보 = 급락 정밀도 50%·적중 3일, 급등 정밀도 75%·적중 2일(급등일이 34~48%로 흔해 50%로는 경보가 주의보다 낮아져서 올림).
- 2020~2022 자료는 `data/raw/backfill_2020/`(운영 로더 미사용)에서 읽어 피처를 운영과 같은 정의로 다시 만듦. 2023 이후 운영 피처 표와 값 대조 일치.

**한 줄 결론**
- 급락: 휴일 급락 36구간 중 31구간(86%)을 전날 15시에 주의 이상으로 잡음(경보 24). 평일 3구간(모두 13시 1시간, 학습 기간엔 평일 급락 없음)은 1구간.

**시기별**(그림 F1): 급락은 학습 급락이 적던 2025년에도 86~100% — 문턱이 느슨했기 때문. 2026년엔 문턱이 엄격해져 경보↓·주의↑, 2026 2분기 2구간(6/13, 6/27) 놓침. 2025-12 경보 헛경보 11일은 그달 대체 규칙(경보 문턱 = 주의 문턱) 탓.

## 4. 해 보니 이랬다 (사후 분석, 참고)
1. 가격은 실제 날씨가 아니라 **거래소의 전날 전망**을 따른다: 15시엔 못 쓰는 거래소 D일 수요예측을 넣으면 급락 PR-AUC 0.39→0.50, 실측 태양광은 0.42로 거의 그대로.
2. 날씨 예보가 급락의 핵심(빼면 0.39→0.26). 2020~2022 자료·주간전망·연료비는 효과가 드러나지 않음.
3. 급락 두 모델 평균 ≈ LSTM 혼자, LightGBM 혼자는 더 나쁨.
4. 새 기준 급등은 상당 부분 '가격 수준 이동'(그날 평균이 기준보다 10원 이상 높으면 거의 다 급등) → 하루 단위 수요·날씨로는 ROC-AUC 0.65 근처에서 막힘.
