# 제주 ① 급락일 레이블링과 특성

작성: 2026-10-19 · 스크립트: `python -m drop_classifier.src.label_days 제주`

## 1. 급락 정의: 육지와 같은 기준 유지
- 11~15시 제주 SMP 최저 < 30원 → 급락. 10원 미만도 30원 미만과 같은 135일 → 기준값에 둔감.
- 30원 미만 355시간 중 323시간이 11~15시. 새벽(3~6시) 16시간 등 창 밖 20시간은 별도 현상(풍력 추정)이라 레이블에 넣지 않음.

## 2. 발생 현황

|---|---|---|---|---|---|
| 급락일 | 2 | 0 | 20 | 60 | 53 |

| 구간 | 일수 | 급락일 | 비율 |
|---|---|---|---|
| 학습 2024-01 ~ 2026-06 | 912 | 124 | 13.6% (육지 4.6%) |
| 검증 2026-07 ~ 10-18 | 110 | 9 | 8.2% |

- 학습 구간 요일유형별: 평일 9.7%(59일), 주말 20.8%, 공휴일 20.0%, 연휴 25.0%.
- 월별(2024~): 3월 32일로 최다, 6~8월 거의 없음(6월 4, 7·8월 0).

## 3. 육지와의 관계

- **2024년 이후 육지 급락 47일은 모두 제주에서도 급락.** 제주 급락 133일 = 육지 동반 47일 + **제주만 86일**.
- 평소 제주·육지 시간별 가격이 같은 비율은 80~90%, **제주 급락일 13시에는 34%** → 제주 재생에너지가 남아 연계선으로 다 보내지 못할 때 제주 가격만 꺼지는 구조로 추정.
- 제주·육지 가격 동일 비율이 2026년 3분기 99%로 높아짐 → 연계가 강해지는 추세. 제주만 급락하는 날이 줄어들 가능성.

- 순부하(수요예측 − 태양광·풍력 실적) 5분위별 급락 비율: 하위 20% 29% → 18% → 5% → 2% → 상위 20% 0%.
- 제주 급락 = **육지 급락 국면(휴일·저수요)** + **제주 재생에너지 과잉(평일 포함, 맑고 바람 강하고 수요 낮은 날)**.

## 6. 모델 설계에 주는 시사점
- 육지 하루 전 모델의 위험 점수를 제주 모델의 입력으로 사용 (육지 급락이면 제주도 급락).
- 제주 고유 요인: 제주 수요예측, 하늘상태·풍속 예보(제주 지점), 최근 제주 SMP·결정 연료원(HVDC·재생에너지).
- 급락 비율이 13.6%로 육지보다 높아 분류 모델·트리 모델이 육지보다 유리할 수 있음 → 후보를 다시 비교.
- **제주 단기예보 공백**: 제주(184) 2024-01 ~ 2025-10만 확보. 2025-11 이후(롤링2·검증 기간)가 비어 있음.
