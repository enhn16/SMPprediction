피처 묶음
- **기본(날씨 없음)**: 달력(휴무일·연휴·명절·월) + 수요예측(D일) + 시차 SMP(D-1 이전)
- **예보**: 기본 + D-1 17시 단기예보(하늘상태·강수확률·강수·기온·풍속, 육지 7개 지점 평균)
- **예보·수요예측 D-1**: 예보 묶음에서 D일 수요예측을 D-1일 수요예측으로 바꿈 (아래 4절)
- **상한선(실측 날씨)**: 기본 + ASOS 실측(운량·일조·일사·기온) — 실제 예측에는 쓸 수 없음

## 2. 모델 비교 (롤링 PR-AUC 평균)

| 모델 | 기본 | **예보** | 예보·수요예측 D-1 | 상한선(실측) |

| **로지스틱** | 0.556 | **0.603** | 0.559 | 0.558 |
| CatBoost | 0.465 | 0.596 | 0.528 | 0.494 |
| EBM | 0.526 | 0.579 | 0.533 | 0.495 |

| 규칙: 휴무일+맑음 예보 | | 0.177 | | |

- **선택: 로지스틱 + 예보 묶음.** 1위이고 해석 가능. CatBoost와 차이 0.007로 의미 없음.
- 모델이 단순 규칙보다 PR-AUC 2~3배 높음.
- **날씨 예보가 도움이 됨**: 로지스틱 0.556 → 0.603, EBM 0.526 → 0.579.
- **실측 날씨(상한선)가 예보보다 낫지 않음.** 실측을 써도 더 나아질 여지가 거의 없다는 뜻. 한낮 하늘상태 예보가 이미 충분히 정확하거나, 남은 오차가 날씨가 아닌 다른 요인(공급 측 등)에서 온다는 뜻.
- 롤링 두 번 모두 로지스틱·EBM·CatBoost가 상위권 (순위 일관). 결정나무는 깊이 3으로는 표현력이 부족함.

## 4. 요인 해석

로지스틱 표준화 계수 (음수 = 값이 클수록 급락 가능성 낮음)

| 요인 | 계수 | 해석 |
|---|---|---|
| 수요예측 | −1.58 | 가장 강함. 수요가 낮을수록 급락 |
| 직전 같은 유형일 최저 SMP | −0.87 | 최근 같은 유형의 날 SMP가 낮았으면 급락 쉬움 (시장 상황 지속) |
| 기온 예보 | −0.59 | 더울수록 급락 어려움 (냉방 수요) |
| 수요예측(28일 대비) | −0.56 | 평소보다 수요가 낮은 날 급락 |
| 월(cos) | +0.46 | 겨울~봄 쪽이 급락 쉬움 |
| 명절 | +0.44 | 명절 연휴는 같은 조건에서도 급락 쉬움 |
| 휴무일 × 하늘상태 | −0.41 | **휴무일에 흐리면 급락 가능성 감소** = "휴일 + 맑음" 효과 |

- EBM은 "수요예측 × 하늘상태" 상호작용을 5번째로 중요하게 잡음 → 수요가 낮을 때 날씨 효과가 커짐(②와 일치).
- 3일 이상 연휴 계수(−0.62)는 명절·휴무일·연휴 길이 변수와 겹쳐서 생긴 값이라 단독으로 해석하지 않는다.

## 5. 수요예측 공개 시각 문제

data.go.kr API의 D일 하루전 수요예측은 **D-1 23시경** 공개되어 판단 시각(17시)보다 늦다. D-1일 수요예측으로 바꾸면 롤링 PR-AUC가 0.603 → 0.559로 0.044 떨어진다. 사내에서 D일 수요예측을 17시 전에 받을 수 있는지 확인이 필요하다.

## 6. 잔차 분석 (재현율 우선 기준, 롤링 OOF에서 놓친 급락 10일)

| 구분 | 급락확률 중앙값 | 수요예측 중앙값 | 28일 대비 | 하늘상태 예보 | 실측 운량 |
|---|---|---|---|---|---|
| 적중 (29일) | 0.41 | 43,965 MW | 0.72 | 1.37 | 1.94 |
| 놓침 (10일) | 0.06 | 47,672 MW | 0.78 | 2.19 | 1.81 |

- **놓친 날은 수요가 덜 낮고 예보가 더 흐렸다.** 다만 실측 운량은 적중일과 비슷 → 일부는 **예보가 실제보다 흐리게 나온 날**(예: 2025-01-01 예보 2.1 vs 실측 0.06, 2025-02-22 1.6 vs 0.4).
- **실제로도 흐렸는데 급락한 날**: 2025-03-15(실측 운량 8.6), 2025-04-20(7.4), 2026-06-27(5.1), 2026-02-22(4.1) → 날씨·수요로 설명되지 않음. **공급 측 요인 후보**(원전 출력, 양수 운전, 재생에너지 출력제어 등).
- **2025-11-26(수)**: 평일·수요 평범(28일 대비 1.06)·약간 맑음 → 현재 피처로 설명 불가. 공급 측 확인 대상.
- 발전원별 발전량(원전 등) 비교는 API 일일 호출 한도(약 100회) 소진으로 **보류**. 다음 날 `python -m common.collect.gen_by_fuel <날짜들>`로 받은 뒤 `03_errors_육지.csv`에 원전 비중을 붙여 비교한다.
