기준선과 비교 (같은 3개 구간 합계)

| 방법 | 적중 / 급락일 | 헛경보 |
|---|---|---|
| **선택 모델 (운영형)** | **29 / 39 (74%)** | **39** |
| 규칙: 휴무일이면 급락 | 36 / 39 (92%) | 184 |
| 규칙: 휴무일 + 맑음 예보 | 22 / 39 (56%) | 64 |

- "휴무일이면 급락" 규칙보다 헛경보가 **184일 → 39일로 79% 줄고**, 적중은 7일 적다.
- "휴무일 + 맑음" 규칙보다 **적중은 7일 많고 헛경보는 25일 적다.**
- 적중률을 규칙 수준(90%)까지 올리면 모델도 헛경보가 크게 늘어난다(롤링 기준 약 119일, 규칙은 151일). 남은 10일은 날씨·수요로 설명되지 않는 급락이 대부분이다(③ 6절).
- 주의: 운영형 임계값은 롤링 평가 예측으로 정했으므로 롤링1·2 수치는 약간 낙관적이다. **검증 기간 수치는 임계값 결정에 쓰지 않은 깨끗한 결과**이나 급락일이 5일뿐이다.

## 5. 실패 사례 해설

- **9/25 추석 (실제 0원, 기존 예측 72.65원)**: 하늘상태 예보는 흐림(3.9)이었지만 수요예측이 33,716 MW로 분석 기간 최저(28일 대비 55%)라 급락확률 0.24 → 경보. 맑음보다 **극단적으로 낮은 수요**가 원인.
- **10/5 대체공휴일 (실제 106원, 기존 예측 68원)**: 연휴 3일째지만 수요예측 47,160 MW(28일 대비 84%)로 평범하고 하늘도 중간 → 급락확률 0.03, 경보 없음. "휴무일" 규칙은 이날 헛경보.

## 6. 예보 기반 vs 상한선(실측 날씨)

| 피처 | PR-AUC (롤링 평균) | 적중 / 급락일 (3구간) | 헛경보 |
|---|---|---|---|
| 기본 (날씨 없음) | 0.556 | 29 / 39 | 41 |
| **예보** | **0.603** | 29 / 39 | 39 |
| 상한선 (실측 날씨) | 0.558 | 28 / 39 | 33 |

실측 날씨를 써도 적중이 늘지 않음 → 날씨 정확도를 더 올려도 개선 여지가 작다. 남은 개선 여지는 공급 측(원전·출력제어 등) 정보에 있을 가능성이 크다.

## 7. 한계와 후속 과제

1. **검증 기간 급락 5일**: 100% 적중은 표본이 작아 우연의 몫이 크다. 롤링 포함 74%가 현실적인 기대치.
2. **D일 수요예측 확보 시각**: 사내에서 17시 전 확보가 안 되면 D-1 수요예측 버전(롤링 PR-AUC 0.559)으로 바꿔야 한다.
3. **놓친 급락 10일**: 흐린 날 급락, 평범한 평일 급락. 발전원별 발전량(원전 비중) 비교 예정 — API 일일 한도로 보류.
4. **공급 측 데이터 후보**: 원전 일별 송전량(한수원), 발전원별 실시간 현황(전력거래소 현황조회 API, 키 반영 대기). 실시간 API는 과거 이력이 없으므로 지금부터 매일 수집해야 학습에 쓸 수 있다.
5. **제주**: 같은 파이프라인으로 진행 예정.
