## 1. SMP (전력거래소, xlsx 10개)

- 파일: `smpInLand_{2022~2026}.xlsx`, `smpJeju_{2022~2026}.xlsx`

  - 컬럼: `날짜`(정수 YYYYMMDD), `1h`~`24h`, `최대`, `최소`, `평균`
  - 시간 표기 1~24시, 단위 원/kWh, **시간 단위**(제주도 15분 아님)
- 기간: 2022-01-01 ~ 2026-10-18, **누락일·결측·중복 없음**

| 2023 | 59.83 | **0** | 59.83 | 0 | 0 | **0** |

## 5. API로 확인한 데이터 (2026-10-18 호출 시험)

### 계통한계가격 및 수요예측(하루전 발전계획용) — 사용 가능
- 엔드포인트: `https://apis.data.go.kr/B552115/SmpWithForecastDemand/getSmpWithForecastDemand`
- 파라미터: `serviceKey`, `pageNo`, `numOfRows`, `dataType=json`, `date=YYYYMMDD`
- 응답: `date`, `hour`, `areaName`(육지/제주), `smp`, `mlfd`(육지 수요예측 MW), `jlfd`(제주 수요예측 MW), `slfd`(합계 = mlfd + jlfd), `rn`
  - 한 날짜에 48행(24시간 × 육지/제주). `mlfd`·`jlfd`는 육지·제주 행에 같은 값이 반복됨
  - `hour` 표기가 `"1"`과 `"01"`로 섞여 있음 → 정수 변환 필요
- 조회 기간: **2020-01-01 ~ 다음 날** (2019-12-31 이전은 0건). 날짜 없이 호출하면 다음 날(D+1) 값을 줌 → 매일 23시경 갱신, 전날 확보 가능
- SMP 값이 xlsx와 일치 (2026-09-25 12시 0원, 13시 7.09원)
- 하루전 수요예측 12시 육지: 2026-09-25 32,224 MW, 2026-10-05 46,245 MW
- BTM 태양광 반영 여부는 공식 설명 없음 → 확인 필요

### ASOS 시간자료 — 사용 가능
- `AsosHourlyInfoService/getWthrDataList`, 2026년 조회 가능. 일사(`icsr`), 일조(`ss`), 전운량(`dc10Tca`), 기온(`ta`) 포함
- 참고: 2026-09-25 12~13시 광주는 전운량 10, 일조 0 (흐림)

### 발전원별 발전량 (data.go.kr 15106744) — 사용 가능, 용도 제한
- 엔드포인트: `https://apis.data.go.kr/B552115/PvAmountByPwrGen/getPvAmountByPwrGen`
- 파라미터: `serviceKey`, `pageNo`, `numOfRows`, `dataType=json`, `tradeYmd=YYYYMMDD`
- 응답: `tradeYmd`, `tradeNo`(시간), `fuelTpCd`(발전원), `amgo`(발전량), `rn`. 하루 192행(24시간 × 8개 발전원)
- 발전원: LNG, 무연탄, 수력, **신재생·기타**, 양수, 원자력, 유연탄, 유전 → **태양광·풍력이 따로 없음**
- 조회 기간: 2021-01-01 ~ 2026-08-30 전후 (정산 데이터라 약 1.5개월 늦음, 2020년은 0건)
- **2026-06-30부터 `신재생·기타`가 전부 0** → 아직 정산 전으로 보임. 검증 기간 재생에너지 용도로는 사용 불가
- 2021-01-01 신재생 일합계(3,339)가 2022-01-01(76,877)보다 훨씬 작음 → 집계 기준이 바뀌었을 수 있음
- 용도: 원전·석탄·LNG 등 공급 측 구성 확인(③ 잔차 분석). 실적이라 예측 피처로는 쓰지 않음

### 발전원별 발전량 현황조회 (실시간) — 활용신청 완료, 키 반영 대기 (1~2시간)
- `https://openapi.kpx.or.kr/openapi/sumperfuel5m/getSumperfuel5m` → `SERVICE KEY IS NOT REGISTERED`
- 응답 항목(포털 설명): 태양광(시장), 풍력, 신재생, PPA 추정, BTM 추정, 시장수요 등 (MW). 날짜 지정 파라미터 없음 → 실시간 전용으로 보임

## 7. 2026년 실적 데이터가 없는 이유
- data.go.kr의 `시간별 전국 전력수요량`, `지역별 시간별 태양광 및 풍력 발전량`, `지역별 5분단위 태양광 계량데이터`는 **연 1회 갱신**. 2025년분이 2026년 3~4월에 등록됐고, 2026년분은 **2027년 3~4월 예정**.
