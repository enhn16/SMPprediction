# 과제4: SMP 급등 판단

> 공통 규칙은 루트 [CLAUDE.md](../CLAUDE.md)를 따른다. 매 세션 이 파일과 [docs/PLAN.md](docs/PLAN.md)를 읽고, 체크리스트에서 현재 진행 단계를 확인한 뒤 작업한다.

## 1. 과제 맥락

- **목적**: 급락의 반대편 — 가격이 평소와 다르게 확 뛰는 날을 전날 판단한다. 과제1(급락)과 같은 3단계(레이블 → 요인 비교 → 분류 모델)로 진행.
- **핵심 질문**: "내일 SMP가 평소보다 크게 오르는가?"를 **D-1 15:00**에 예측하는 **이진 분류**.
- **대상**: 육지 먼저. 휴일 한정 없이 **전체 날짜**, 시간도 하루 전체 (최고가 발생 시각은 따로 기록).
- 계기가 된 사례: 2026-10-13(화, 한낮 176원, 흐려서 태양광 절반), 2026-10-20(화, 19시 한 시간 166원).

## 2. 급등 정의 (현업 기준안, 2026-10-26 수령)

- **그날 최고 SMP ≥ 직전 28일 「일 최고 SMP」 중앙값 × 1.25 → 1** (일 단위)
- 고정 금액(예: 200원)이 아닌 이유: SMP 수준이 연료비에 따라 해마다 다름 (일 최고 중앙값 2022년 210원 → 2025년 138원).
- 직전 28일: 그날 이후 정보를 쓰지 않고 최근 수준을 반영. 기준값은 D-1 15시에 이미 알 수 있다.
- +20%·+30%로 바꿨을 때의 결과도 함께 제시 (민감도).
- **매월 1~3일은 연료비 단가 변경으로 가격 수준 자체가 오를 수 있어 따로 표시** (`is_fuel_change_window`).
- SMP는 전력거래소 원본(2022-01~)만 쓴다. 현업 표(담당자 파일 `smp_dataset_hourly.csv`, 12종 밖)는 2026-10-26에 한 번 재현 확인만 함.
- **21시(2차) 판정 중 내일 SMP가 공표된 날은 '확인'이지 예측이 아니다.** SMP는 하루 전 확정 가격이라 공표값 = 실제값 = 레이블 원천 → 항상 맞음. 예측 성능은 15시와 21시 공표 전(화요일 판단)분으로만 말한다.

## 3. 평가

- **성공 기준**: 과제1과 동일 — 재현율 80%에서 헛경보 수.
- 팀 규칙: 2023~2024 학습 → 2025 검증으로 선택, 2023~2025 재학습 → **2026-01-01 ~ 10-18 한 번 채점** (2026-10-26 완료, 결과는 PLAN.md ③).
- 비교 기준선: 단순 규칙(평일, 평일 + 흐림 예보, 지속성, 기후값).

## 4. 폴더

```
surge_classifier/
├─ CLAUDE.md          이 파일
├─ docs/              PLAN.md, 분석 결과 정리
├─ src/               레이블, 피처, 모델
└─ outputs/figures|tables
```
- 정제 데이터는 `../data/processed/surge_classifier/`에 저장.
- **데이터는 팀 목록 12종만** (루트 CLAUDE.md). 과제1 피처 테이블은 목록 밖 자료(단기예보 격자·ASOS)가 섞여 있어 쓰지 않고, `src/features.py`가 12종으로 새로 만든다.
- 실행 순서 (루트에서): `python -m surge_classifier.src.label_days` → `.features` → `.compare` → `.models` (2026 채점 포함, 다시 돌려도 같은 결과) → `.ops_surge` (운영 함수 검증)
- 결과 형식은 ROLES.md 4.1 (`kind=surge`): `outputs/tables/surge_육지_{15h,21h}.csv`, `surge_choice_육지_{stage}.json`, `surge_score_육지_{stage}.csv`, 운영 함수 `src/ops_surge.predict(bases, stage)`. (예전 계획의 `surge_prob_{계통}.csv`는 4.1 형식으로 대체)
